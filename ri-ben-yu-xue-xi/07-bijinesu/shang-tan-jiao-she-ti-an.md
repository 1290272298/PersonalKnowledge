# 商談・交渉・提案

## 1. このテーマについて

商談・交渉では、相手の要望を聞き、自社の提案や条件を説明し、双方が納得できる合意点を探します。相手の立場を尊重しながら、根拠を示して話すことが大切です。

## 2. 提案を始める表現

* 本日は、改善案をご提案いたします。
* こちらの資料をご覧いただけますでしょうか。
* 現状を踏まえ、次の方法を提案いたします。
* 主なメリットは三点ございます。
* ご要望に沿って、内容を調整いたしました。

## 3. 条件・交渉に関する語彙

| 語彙   | 読み方       | 意味              |
| ---- | --------- | --------------- |
| 前提条件 | ぜんていじょうけん | 話を進めるための基本条件    |
| 対応範囲 | たいおうはんい   | 実施・提供する範囲       |
| 見積もり | みつもり      | 費用や数量の事前計算      |
| 納期   | のうき       | 納品する期限          |
| 代替案  | だいたいあん    | 別の方法や案          |
| 譲歩   | じょうほ      | 条件の一部を相手に合わせること |
| 合意   | ごうい       | 双方の意見が一致すること    |
| 保留   | ほりゅう      | すぐに決めず、後で判断すること |

## 4. 反対・調整を伝える表現

* ご意見は理解いたしました。
* その条件では対応が難しい状況です。
* 別の方法をご提案してもよろしいでしょうか。
* 納期を一週間延長いただくことは可能でしょうか。
* 社内で確認のうえ、改めて回答いたします。

## 5. 会話例

**提案者：今回、作業工程を見直す案をご提案いたします。**

**顧客：費用への影響はありますか。**

**提案者：初期費用は発生しますが、運用後の作業時間を削減できる見込みです。**

**顧客：納期を短縮することは可能でしょうか。**

**提案者：対応範囲を調整できれば、短縮できる可能性があります。代替案を作成してご提示いたします。**

## 6. 注意点

* 相手の要望を最後まで聞き、認識を確認してから提案する。
* メリットだけでなく、費用・期間・リスクも説明する。
* 合意していない内容を決定事項のように伝えない。
* 口頭で合意した内容も、必要に応じて文書で確認する。

## 7. 練習問題

### 問題1：文に合う語彙を選びましょう。

1. 別の方法や案：（代替案・納期）
2. 双方の意見が一致すること：（合意・保留）
3. 条件の一部を相手に合わせること：（譲歩・見積もり）

### 問題2：条件の変更を丁寧に依頼する文を作りましょう。

### 問題3：商談で説明すべき項目を三つ挙げましょう。

## 8. 解答・解説

### 問題1

1. 代替案
2. 合意
3. 譲歩

### 問題2

例：恐れ入りますが、納期を一週間延長いただくことは可能でしょうか。

### 問題3

例：提案内容、費用、納期、対応範囲、メリット・リスクなど。

## 9. まとめ

商談・交渉では、相手の要望を理解し、根拠と条件を明確にして提案することが重要です。合意内容は双方で確認し、誤解を防ぎましょう。
