# 進捗管理・スケジュール

## 1. 進捗管理とは

進捗管理は、計画に対して作業がどこまで進んでいるかを確認し、遅れや課題に早めに対応することです。作業内容・担当者・期限・完了条件を明確にしましょう。

## 2. 進捗を表す語彙

| 語彙  | 読み方     | 意味              |
| --- | ------- | --------------- |
| 着手  | ちゃくしゅ   | 作業を始めること        |
| 対応中 | たいおうちゅう | 現在作業している状態      |
| 完了  | かんりょう   | 作業が終わった状態       |
| 保留  | ほりゅう    | 一時的に判断・作業を止めること |
| 遅延  | ちえん     | 予定より遅れること       |
| 前倒し | まえだおし   | 予定を早めること        |
| 延期  | えんき     | 予定を後にすること       |
| 工数  | こうすう    | 作業に必要な時間・人員の量   |
| 納期  | のうき     | 成果物を納める期限       |
| 優先度 | ゆうせんど   | 先に対応する必要性の高さ    |

## 3. 進捗を報告する表現

* 現在、予定の七割程度まで完了しています。
* 本日中に着手する予定です。
* 一部の作業に遅れが発生しています。
* 原因を確認し、対応策を検討しています。
* 予定より一日早く完了する見込みです。

## 4. スケジュール調整の表現

* 日程を再調整させていただけますでしょうか。
* 作業を一日前倒しにすることは可能です。
* 納期を二営業日延長する必要があります。
* 影響範囲を確認したうえで、改めて予定を共有します。

## 5. 進捗確認の基本項目

| 項目   | 確認内容           |
| ---- | -------------- |
| 作業内容 | 何を実施するか        |
| 担当者  | 誰が実施するか        |
| 予定日  | いつまでに実施するか     |
| 実績   | 現在どこまで進んだか     |
| 課題   | 遅延・障害・確認待ちがあるか |
| 次の対応 | 誰がいつまでに何をするか   |

## 6. 会話例

**上司：テスト工程の進捗はいかがですか。**

**担当者：予定の八割が完了しています。一件の不具合が残っており、原因を調査中です。**

**上司：リリース日程への影響はありますか。**

**担当者：現時点では影響はありませんが、明日の午前中に再確認してご報告いたします。**

## 7. 練習問題

### 問題1：意味に合う語彙を選びましょう。

1. 作業を始めること：（着手・完了）
2. 予定より遅れること：（遅延・前倒し）
3. 予定を後の日に変更すること：（延期・着手）
4. 成果物を納める期限：（納期・工数）

### 問題2：進捗報告に含める情報を三つ挙げましょう。

### 問題3：遅延が発生した場合の報告文を作りましょう。

## 8. 解答・解説

### 問題1

1. 着手
2. 遅延
3. 延期
4. 納期

### 問題2

例：現在の進捗、遅延・課題の有無、原因、今後の対応、完了見込みなど。

### 問題3

例：現在、確認作業に一日の遅れが発生しています。原因を調査し、明日午前中までに対応方針をご報告いたします。

## 9. まとめ

進捗管理では、予定と実績の差を早めに把握し、課題・影響・次の対応を具体的に共有することが重要です。
