# 07 ビジネス日本語

## 1. このカテゴリーについて

このカテゴリーでは、日本の職場で必要となる敬語、メール、電話、会議、報連相、商談、進捗管理、業務文書、面接表現を学びます。表現を暗記するだけでなく、相手・目的・状況に合わせて使い分けることを目指します。

## 2. 学習内容

| テーマ      | 学習する内容           |
| -------- | ---------------- |
| ビジネス敬語   | 尊敬語・謙譲語・丁寧語、依頼表現 |
| ビジネスメール  | 件名、宛名、依頼、報告、結び   |
| 電話応対     | 受電、取次、不在対応、折り返し  |
| 会議・打ち合わせ | 議題、意見、確認、決定、議事録  |
| 商談・交渉・提案 | 提案、条件調整、代替案、合意   |
| 報連相      | 報告・連絡・相談の使い分け    |
| 業務文書・報告書 | 目的、対象、手順、結果、注意事項 |
| 進捗管理     | 予定、実績、課題、遅延、期限   |
| 面接・自己紹介  | 経歴、強み、実績、志望理由    |

## 3. 学習のポイント

* 相手が社内の人か社外の人かを意識して敬語を選ぶ。
* 依頼では、目的・期限・必要な対応を明確にする。
* 報告では、結論・理由・影響・次の対応を整理する。
* メールや文書では、事実・推測・予定を区別する。
* 会議や商談では、決定事項・担当者・期限を確認する。

## 4. おすすめの学習方法

1. 各テーマの表現と使い分けを読む。
2. 会話例・メール例を声に出して確認する。
3. 自分の職場や業務に置き換えて文を作る。
4. 練習問題で適切な表現を選べるか確認する。
5. 実際に使った表現を記録し、より自然な言い方に修正する。

## 5. 自己確認

* [ ] 尊敬語と謙譲語を使い分けられる。
* [ ] 社外向けのメールを基本構成に沿って書ける。
* [ ] 電話で名乗り、用件を聞き、担当者へ取り次げる。
* [ ] 会議で意見・質問・決定事項を伝えられる。
* [ ] 報告・連絡・相談を目的に応じて使い分けられる。
* [ ] 進捗や課題を具体的に報告できる。

## 6. まとめ

ビジネス日本語では、正しい敬語だけでなく、相手が必要とする情報を分かりやすく伝えることが重要です。実務の場面を想定して、表現を繰り返し練習しましょう。
