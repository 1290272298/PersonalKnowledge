# 業務文書・報告書の表現

## 1. 業務文書の基本構成

業務文書では、目的・対象・前提・手順・結果・注意事項を整理し、読み手が誤解しないように書きます。

| 項目 | 内容        | 表現例                  |
| -- | --------- | -------------------- |
| 目的 | 文書を作成する理由 | 本書の目的は、～を明確にすることである。 |
| 対象 | 適用する範囲    | 本手順は、～を対象とする。        |
| 前提 | 実施前に必要な条件 | 事前に～が完了していること。       |
| 手順 | 実施する順序    | 以下の手順に従って実施する。       |
| 結果 | 実施後の状態    | 正常に完了したことを確認した。      |
| 注意 | 制約・補足     | ただし、～の場合は対象外とする。     |

## 2. 報告書で使う表現

* ～を実施した結果、次のことが確認された。
* 主な原因は～であると考えられる。
* 現時点では、～への影響は確認されていない。
* 今後は、～を実施する予定である。
* 詳細については、別紙を参照されたい。

## 3. 接続表現の使い分け

| 表現    | 働き          |
| ----- | ----------- |
| なお    | 補足情報を加える    |
| ただし   | 条件・例外を示す    |
| 一方    | 対比する        |
| そのため  | 原因から結果を導く   |
| したがって | 前の内容から結論を導く |
| 例えば   | 具体例を示す      |

## 4. 曖昧さを避ける書き方

* 「早めに」ではなく「〇月〇日までに」と具体的に書く。
* 「対応する」だけでなく、担当者・作業内容・完了条件を書く。
* 「問題ない」ではなく、何を確認して問題がないのかを書く。
* 事実、推測、予定を区別して記載する。

## 5. 記載例

**悪い例：** 確認したところ、問題ありませんでした。今後対応します。

**改善例：** 対象データ100件を確認した結果、必須項目の未入力はありませんでした。今後は、同様の確認を月次で実施する予定です。

## 6. 練習問題

### 問題1：適切な接続表現を選びましょう。

1. 予定どおり作業は完了した。（ただし・例えば）、一部の確認事項が残っている。
2. 必要なデータが不足していた。（そのため・なお）、処理を開始できなかった。
3. 次の作業は二つある。（例えば・したがって）、データ確認と結果報告である。

### 問題2：曖昧な表現を具体的に直しましょう。

「できるだけ早く確認してください。」

### 問題3：報告書で事実と推測を区別する理由を説明しましょう。

## 7. 解答・解説

### 問題1

1. ただし：完了した内容に例外・補足を加えます。
2. そのため：データ不足が処理開始できなかった原因です。
3. 例えば：二つの作業の具体例を示します。

### 問題2

例：11月10日15時までに確認してください。

### 問題3

事実と推測を区別しないと、読み手が確定情報と予測を誤解するためです。判断や対応の根拠を明確にする必要があります。

## 8. まとめ

業務文書では、目的・対象・手順・結果を整理し、具体的で検証可能な表現を使いましょう。事実と推測、決定事項と予定を明確に区別することが重要です。
