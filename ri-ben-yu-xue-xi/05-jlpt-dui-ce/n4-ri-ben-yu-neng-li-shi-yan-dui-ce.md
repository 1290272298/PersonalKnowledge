# N4 日本語能力試験対策

## 1. N4の学習目標

N4では、日常的な場面で使われる日本語をある程度理解できることを目指します。基本的な語彙に加えて、普通形、授受表現、可能・受身などの文法を使い、少し長い文章や会話を理解する練習をします。

## 2. 学習する内容

| 分野    | 学習内容                 | 学習のポイント       |
| ----- | -------------------- | ------------- |
| 文字・語彙 | 日常生活、学校、買い物、移動の漢字・語彙 | 熟語と読み方を覚える    |
| 文法    | 普通形、授受、可能、受身、条件、理由   | 接続と意味を確認する    |
| 読解    | 身近な話題の説明文、案内、手紙      | 文のつながりと要点を読む  |
| 聴解    | 日常会話、予定や依頼のやり取り      | 会話の目的と次の行動を聞く |

## 3. よく確認したい文法

* ～と思います／～と言いました
* ～てあげる／～てくれる／～てもらう
* 可能形・受身形
* ～たことがあります
* ～ながら
* ～ので／～のに
* ～たら／～ば／～と
* ～なければなりません／～なくてもいいです

## 4. オリジナル練習問題

### 問題1：文に合う文型を選びましょう。

1. 日本へ行った（ことがあります・ことにします）。
2. 友達が駅まで迎えに来て（くれました・あげました）。
3. 雨が降った（ので・のに）、試合は中止になりました。
4. 音楽を聞き（ながら・まま）、勉強します。

### 問題2：正しい形に直しましょう。

1. 食べる → 可能形
2. 書く → 受身形
3. 行く → た形

### 問題3：短い文章を読みましょう。

「山田さんは来月から新しい会社で働きます。通勤時間を短くするために、会社の近くへ引っ越すことにしました。」

1. 山田さんはいつから新しい会社で働きますか。
2. どうして引っ越すことにしましたか。

## 5. 解答・解説

### 問題1

1. ことがあります：過去の経験を表します。
2. くれました：相手が自分のために行った行為です。
3. ので：中止になった理由を表します。
4. ながら：二つの動作を同時に行います。

### 問題2

1. 食べられる
2. 書かれる
3. 行った

### 問題3

1. 来月からです。
2. 通勤時間を短くするためです。

## 6. 学習のポイント

* 普通形と丁寧形を変換する練習をする。
* 似た文型は、接続・意味・使う場面を比較する。
* 読解では、理由や目的を示す表現に注目する。
* 聴解では、依頼や提案の後に何をするかを聞き取る。

## 7. まとめ

N4では、基本文法を使って日常的な出来事や経験を説明できることが大切です。文型を暗記するだけでなく、会話や文章の中で使い分けましょう。
