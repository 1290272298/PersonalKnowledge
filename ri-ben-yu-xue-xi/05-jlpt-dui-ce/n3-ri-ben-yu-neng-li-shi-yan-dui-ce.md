# N3 日本語能力試験対策

## 1. N3の学習目標

N3では、日常的な話題に加え、少し抽象的な内容や説明文を理解する力を身につけます。語彙・文法の意味を文脈から判断し、文章や会話の要点をつかむ練習が重要です。

## 2. 学習する内容

| 分野    | 学習内容           | 学習のポイント      |
| ----- | -------------- | ------------ |
| 文字・語彙 | 抽象語彙、類義語、漢字熟語  | 文脈と共起表現で判断   |
| 文法    | 複文、接続、推量、判断、条件 | 似た文型の違いを整理   |
| 読解    | 説明文、意見文、案内文    | 主張・理由・具体例を区別 |
| 聴解    | 会話の意図、要点、話の展開  | 話者の目的と結論を聞く  |

## 3. よく確認したい文法・表現

* ～ようにする／～ことにする
* ～ことになっている
* ～ために／～ように
* ～ばかり／～ところ
* ～一方で／～反面
* ～に対して／～について
* ～はずだ／～わけだ
* ～そうだ／～ようだ／～らしい

## 4. オリジナル練習問題

### 問題1：最も適切な表現を選びましょう。

1. 忘れない（ように・ために）、予定を手帳に書きました。
2. 彼は毎日運動する（ことにしています・ことがあります）。
3. この地域では人口が減少する（一方で・ために）、高齢者の割合が増えています。
4. 電車が遅れている（らしいです・つもりです）。駅で案内がありました。

### 問題2：文の要点を読み取りましょう。

「新しい制度を導入した結果、手続きにかかる時間は短くなった。一方で、利用者が操作方法を理解するまでに時間がかかるという課題も残っている。」

1. 制度を導入して、何が改善しましたか。
2. どのような課題が残っていますか。
3. 「一方で」はここでどのような働きをしていますか。

### 問題3：類義表現の違いを説明しましょう。

1. 「ことにする」と「ことになっている」
2. 「ようだ」と「らしい」

## 5. 解答・解説

### 問題1

1. ように：忘れない状態を実現するための工夫です。
2. ことにしています：自分で決めて続けている習慣です。
3. 一方で：二つの異なる状況を対比しています。
4. らしいです：案内から得た情報を伝えています。

### 問題2

1. 手続きにかかる時間が短くなりました。
2. 利用者が操作方法を理解するまでに時間がかかることです。
3. 改善した点と、残っている課題を対比しています。

### 問題3

1. 「ことにする」は自分で決めること、「ことになっている」は規則や予定として決まっていることを表します。
2. 「ようだ」は状況や根拠からの推測、「らしい」は伝聞や典型的な性質を表す場合があります。文脈と接続を確認しましょう。

## 6. 学習のポイント

* 類義文型は意味だけでなく、接続と文脈を比較する。
* 読解では接続詞に注目し、対比・理由・結論の関係を整理する。
* 聴解では、話者が最終的に何を決めたかを聞き取る。
* 抽象語彙は例文と一緒に覚える。

## 7. まとめ

N3では、単語や文型の知識を文章や会話の理解につなげることが大切です。文脈を手掛かりに、要点と細かな意味の違いを読み取る練習を続けましょう。
