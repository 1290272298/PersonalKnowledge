# 01 日本語の基礎｜日语基础入门

本章是完全零基础学习日语的起点。建议按照「文字 → 发音 → 句型 → 助词 → 活用」的顺序学习。

## 1. 本章学完要达到什么程度？

- 看到平假名和片假名，能够读出基本发音。
- 能区分长音、促音、拨音和拗音。
- 能看懂并说出简单的自我介绍。
- 能使用「は、が、を、に、で、の」组成简单句子。
- 能理解动词和形容词的基本变化。

## 3. 先认识一个最简单的句子

**日文：** 私は学生です。

**假名：** <ruby>私<rt>わたし</rt></ruby>は <ruby>学生<rt>がくせい</rt></ruby>です。

**中文：** 我是学生。

| 组成部分 | 假名 | 作用 |
|---|---|---|
| 私 | わたし | 我 |
| は | は（读作 wa） | 提示主题 |
| 学生 | がくせい | 学生 |
| です | です | 礼貌判断，相当于“是” |

**记住：** 日语的「は」如果作为助词使用，读音是 wa，而不是 ha。

## 6. 给零基础学习者的建议

刚开始不需要急着学习N2、N1的复杂语法。先把假名、基础发音和简单句型学扎实。每个例句都建议按「日文 → 假名 → 中文 → 语法说明」的顺序理解，再大声朗读。
