# 01 日本語の基礎

## 1. このカテゴリーについて

このカテゴリーでは、日本語を学ぶために必要な文字・発音・文型・活用の基本を学びます。ひらがな・カタカナから始め、単語を文に組み立てる方法や、動詞・形容詞の活用へと段階的に進みます。

## 2. 学習目標

* ひらがな・カタカナを読み書きできる。
* 日本語の音の長さやリズムの基本を理解する。
* 基本的な語順と文型を使って文を作る。
* 助詞の基本的な働きを理解する。
* 動詞・形容詞の基本的な活用を使い分ける。
* 丁寧体と普通体、非過去と過去を区別する。

## 3. 学習内容

| 順番 | テーマ       | 学ぶ内容                     |
| -- | --------- | ------------------------ |
| 1  | ひらがな・カタカナ | 五十音、濁音、半濁音、拗音            |
| 2  | 発音・音声ルール  | 清音、促音、長音、撥音、アクセント        |
| 3  | 基本文型      | 名詞文、形容詞文、動詞文、疑問文         |
| 4  | 助詞        | は・が・を・に・で・へ・の・と・も・から・まで  |
| 5  | 動詞の分類と活用  | 五段・一段・不規則動詞、ます形、て形、ない形など |
| 6  | 形容詞と活用    | い形容詞・な形容詞の肯定、否定、過去       |
| 7  | 時制と文体     | 非過去・過去、丁寧体・普通体           |

## 4. おすすめの学習順序

1. ひらがなとカタカナを読み書きする。
2. 促音・長音・撥音など、意味に関わる音の違いを練習する。
3. 名詞文・形容詞文・動詞文の基本形を覚える。
4. 助詞を使って、言葉同士の関係を表す。
5. 動詞と形容詞の活用を練習する。
6. 丁寧体と普通体を場面に応じて使い分ける。
7. 各ページの練習問題を解き、間違いを復習する。

## 5. 学習のポイント

* 文字は読む練習と書く練習を組み合わせる。
* 発音では、長音・促音・撥音の長さを意識する。
* 助詞は単独で暗記するだけでなく、例文の中で覚える。
* 動詞・形容詞は活用表を見ながら、自分で変化させる。
* 学んだ文型を使って、自分のことを短い文で説明する。

## 6. 自己確認

次の項目ができるか確認しましょう。

* [ ] ひらがな・カタカナを順番に読める。
* [ ] 「おばさん」と「おばあさん」の音の違いを説明できる。
* [ ] 「私は学生です」のような基本文を作れる。
* [ ] 「学校で勉強します」の助詞「で」の役割を説明できる。
* [ ] 「食べる」を「食べます」「食べない」「食べて」に変えられる。
* [ ] 「高い」と「静か」の活用の違いを説明できる。
* [ ] 丁寧体と普通体を場面に応じて使い分けられる。

## 7. まとめ

日本語の基礎は、その後の文法・語彙・漢字・読解を学ぶための土台です。文字、発音、文型、助詞、活用を順番に身につけ、短い文から自分で作る練習を続けましょう。
