# 日本語の形容詞と活用

## 日本語の形容詞と活用

### 1. 形容詞の種類

日本語の形容詞は、主に2種類に分けられます。

#### い形容詞

基本的に「い」で終わる形容詞です。

例：

* 高い（たかい）
* 安い（やすい）
* おいしい
* 新しい（あたらしい）
* 忙しい（いそがしい）

#### な形容詞

名詞を修飾するときに「な」を付ける形容詞です。

例：

* 静か（しずか）
* 便利（べんり）
* きれい
* 有名（ゆうめい）
* 親切（しんせつ）

注意：「きれい」「有名」などは「い」で終わりますが、な形容詞です。

### 2. い形容詞の活用

| 形    | 変化       | 例        |
| ---- | -------- | -------- |
| 肯定   | ～いです     | 高いです     |
| 否定   | ～くないです   | 高くないです   |
| 過去   | ～かったです   | 高かったです   |
| 過去否定 | ～くなかったです | 高くなかったです |
| て形   | ～くて      | 高くて      |

例文：

* この店は安いです。
* この店は安くないです。
* 昨日は暑かったです。
* この料理はおいしくて、安いです。

### 3. な形容詞の活用

| 形    | 変化          | 例            |
| ---- | ----------- | ------------ |
| 肯定   | ～です         | 静かです         |
| 否定   | ～ではありません    | 静かではありません    |
| 過去   | ～でした        | 静かでした        |
| 過去否定 | ～ではありませんでした | 静かではありませんでした |
| て形   | ～で          | 静かで          |

例文：

* この町は静かです。
* この町は静かではありません。
* 昨日は暇でした。
* この部屋はきれいで、便利です。

### 4. 名詞を修飾する場合

| 種類   | 文型    | 例      |
| ---- | ----- | ------ |
| い形容詞 | ～い＋名詞 | おいしい料理 |
| な形容詞 | ～な＋名詞 | 静かな町   |

例：

* 新しい車を買いました。
* きれいな花が咲いています。

### 5. 形容詞の比較

#### ～より

AよりBのほうが～です。

例：

* 電車より新幹線のほうが速いです。

#### ～ほど～ない

AはBほど～ないです。

例：

* 今日は昨日ほど暑くないです。

#### ～が一番

例：

* この店のラーメンが一番おいしいです。

### 6. 注意すべき形容詞

「いい」は特殊な活用をします。

| 形    | 変化       |
| ---- | -------- |
| 肯定   | いいです     |
| 否定   | よくないです   |
| 過去   | よかったです   |
| 過去否定 | よくなかったです |

### 7. 練習問題

次の形容詞を指定された形に変えてください。

1. 高い → 否定形
2. おいしい → 過去形
3. 静か → 否定形
4. 便利 → 過去形
5. いい → 過去形

### 8. まとめ

形容詞には、い形容詞とな形容詞があります。

それぞれの活用ルールを理解し、肯定・否定・過去の表現を正しく使えるように練習しましょう。

### 9. 解答・解説

1. 高い → 高くないです
2. おいしい → おいしかったです
3. 静か → 静かではありません（静かじゃありません も可）
4. 便利 → 便利でした
5. いい → よかったです

「いい」は特別な活用をし、否定形・過去形では「よい」の形を使います。
