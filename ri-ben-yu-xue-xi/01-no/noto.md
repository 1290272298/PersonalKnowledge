# 日本語の動詞分類と活用

## 日本語の動詞分類と活用

### 1. 動詞の分類

日本語の動詞は、主に3つのグループに分類されます。

#### グループ1：五段動詞

例：

* 書く（かく）
* 読む（よむ）
* 話す（はなす）
* 買う（かう）
* 待つ（まつ）

#### グループ2：一段動詞

例：

* 食べる（たべる）
* 見る（みる）
* 起きる（おきる）
* 寝る（ねる）

#### グループ3：不規則動詞

| 辞書形    | 意味 |
| ------ | -- |
| する     | 做  |
| 来る（くる） | 来  |

### 2. ます形

丁寧な表現に使う形です。

| グループ | 辞書形 | ます形  |
| ---- | --- | ---- |
| 五段   | 書く  | 書きます |
| 五段   | 読む  | 読みます |
| 五段   | 話す  | 話します |
| 一段   | 食べる | 食べます |
| 一段   | 見る  | 見ます  |
| 不規則  | する  | します  |
| 不規則  | 来る  | 来ます  |

### 3. ない形

否定を表す形です。

| グループ | 辞書形 | ない形      |
| ---- | --- | -------- |
| 五段   | 書く  | 書かない     |
| 五段   | 読む  | 読まない     |
| 五段   | 話す  | 話さない     |
| 一段   | 食べる | 食べない     |
| 一段   | 見る  | 見ない      |
| 不規則  | する  | しない      |
| 不規則  | 来る  | 来ない（こない） |

### 4. て形

動作の順序、依頼、進行中の状態などを表します。

#### 五段動詞の変化

| 語尾    | て形 | 例           |
| ----- | -- | ----------- |
| う・つ・る | って | 買って・待って・帰って |
| む・ぶ・ぬ | んで | 読んで・遊んで・死んで |
| く     | いて | 書いて         |
| ぐ     | いで | 泳いで         |
| す     | して | 話して         |

注意：行く → 行って（例外）

#### 一段動詞

「る」を取って「て」を付けます。

* 食べる → 食べて
* 見る → 見て

#### 不規則動詞

* する → して
* 来る → 来て（きて）

### 5. た形

過去の出来事などを表します。

| 辞書形 | た形     |
| --- | ------ |
| 書く  | 書いた    |
| 読む  | 読んだ    |
| 話す  | 話した    |
| 買う  | 買った    |
| 食べる | 食べた    |
| 見る  | 見た     |
| する  | した     |
| 来る  | 来た（きた） |
| 行く  | 行った    |

### 6. 可能形

能力や可能性を表します。

| 辞書形 | 可能形        |
| --- | ---------- |
| 書く  | 書ける        |
| 読む  | 読める        |
| 話す  | 話せる        |
| 食べる | 食べられる      |
| 見る  | 見られる       |
| する  | できる        |
| 来る  | 来られる（こられる） |

### 7. 意向形

自分の意志や勧誘を表します。

| 辞書形 | 意向形      |
| --- | -------- |
| 書く  | 書こう      |
| 読む  | 読もう      |
| 話す  | 話そう      |
| 食べる | 食べよう     |
| 見る  | 見よう      |
| する  | しよう      |
| 来る  | 来よう（こよう） |

### 8. 例文

* 毎日、日本語を勉強します。
* 昨日は本を読みました。

### 9. 練習問題

#### 問題1：動詞のグループを答えましょう。

1. 書く
2. 食べる
3. する
4. 見る
5. 来る

#### 問題2：指定された形に変えましょう。

1. 読む → ます形
2. 話す → ない形
3. 買う → て形
4. 食べる → た形
5. 来る → 可能形

#### 問題3：正しい形を選びましょう。

1. 昨日、図書館で本を（読みます・読みました）。
2. ここで写真を（撮って・撮りて）ください。
3. 私は漢字を（書けます・書きますことができます）。

### 10. 解答・解説

#### 問題1

1. 五段動詞
2. 一段動詞
3. 不規則動詞
4. 一段動詞
5. 不規則動詞

#### 問題2

1. 読みます
2. 話さない
3. 買って
4. 食べた
5. 来られる（こられる）

#### 問題3

1. 読みました：昨日の出来事なので過去形を使います。
2. 撮って：五段動詞「撮る」のて形は「撮って」です。
3. 書けます：可能形で能力を表します。「書くことができます」も正しい表現です。
