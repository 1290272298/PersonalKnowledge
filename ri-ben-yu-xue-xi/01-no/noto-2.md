# 日本語の時制と丁寧体・普通体

## 日本語の時制と丁寧体・普通体

### 1. 日本語の時制

日本語では、主に現在・未来・過去を表現します。

動詞の基本的な時制は「非過去」と「過去」に分けられます。

### 2. 動詞の時制

| 時制  | 肯定形   | 否定形      |
| --- | ----- | -------- |
| 非過去 | 食べます  | 食べません    |
| 過去  | 食べました | 食べませんでした |

例文：

* 毎日、ご飯を食べます。
* 明日、学校へ行きます。
* 昨日、映画を見ました。
* 昨日は勉強しませんでした。

### 3. 丁寧体（ていねいたい）

相手に丁寧に話すときに使う表現です。

主に「です」「ます」を使用します。

例：

* 私は会社員です。
* 毎日、日本語を勉強します。
* 昨日、買い物をしました。

### 4. 普通体（ふつうたい）

友達や家族との会話、親しい関係で使われる表現です。

例：

| 丁寧体       | 普通体    |
| --------- | ------ |
| 学生です      | 学生だ    |
| 食べます      | 食べる    |
| 食べません     | 食べない   |
| 食べました     | 食べた    |
| 食べませんでした  | 食べなかった |
| 高いです      | 高い     |
| 高くないです    | 高くない   |
| 静かです      | 静かだ    |
| 静かではありません | 静かではない |

### 5. 丁寧体と普通体の使い分け

| 場面        | 使用する表現 |
| --------- | ------ |
| 会社の上司との会話 | 丁寧体    |
| 初対面の人との会話 | 丁寧体    |
| 友達との会話    | 普通体    |
| 家族との会話    | 普通体    |
| ビジネスメール   | 丁寧体    |

※ 実際の使い分けは相手との関係や場面によって異なります。

### 6. 普通体を使った文型

#### ～と思う

自分の考えや意見を表します。

例：

* 日本語は難しいと思う。
* 彼は来ないと思う。

#### ～と言う

発言や内容を引用します。

例：

* 彼は明日行くと言った。
* 先生は勉強しなさいと言いました。

#### ～から

理由を表します。

例：

* 雨が降っているから、出かけない。
* 忙しいから、今日は休みます。

### 7. 練習問題

次の文を普通体に変えてください。

1. 私は学生です。
2. 毎日、日本語を勉強します。
3. 昨日、映画を見ました。
4. この料理はおいしいです。
5. この町は静かです。

### 8. まとめ

日本語では、相手や場面に応じて丁寧体と普通体を使い分けます。

また、現在・未来・過去の表現を正しく理解し、自然な会話ができるように練習しましょう。

### 9. 解答・解説

1. 私は学生だ。
2. 毎日、日本語を勉強する。
3. 昨日、映画を見た。
4. この料理はおいしい。
5. この町は静かだ。

名詞文とな形容詞文の普通体では、基本的に「です」を「だ」にします。動詞は「ます」を辞書形に、い形容詞は「です」を取り除きます。
