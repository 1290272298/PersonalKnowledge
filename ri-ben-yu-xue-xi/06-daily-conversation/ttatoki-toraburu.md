# 困ったとき・トラブル対応

## 1. このテーマについて

日常生活で困ったことが起きたときは、状況を整理して相手に伝え、必要な助けや対応を依頼します。落ち着いて、何が・いつ・どこで起きたのかを説明しましょう。

## 2. 助けを求める表現

* すみません、助けていただけますか。
* ちょっと困っているのですが。
* 使い方を教えていただけますか。
* もう一度説明していただけますか。
* どこに連絡すればいいですか。

## 3. トラブルの内容を伝える表現

| 場面       | 表現                 |
| -------- | ------------------ |
| 紛失       | 財布をなくしてしまいました      |
| 故障       | エアコンが動きません         |
| 遅れ       | 電車が遅れていて、到着が遅れそうです |
| 間違い      | 注文した商品と違うものが届きました  |
| 場所が分からない | 道に迷ってしまいました        |
| 予約       | 予約した内容を確認したいのですが   |

## 4. 状況を説明する順番

1. **何が起きたか**：財布をなくしました。
2. **いつ・どこで起きたか**：今日の午後、駅で気付きました。
3. **現在の状況**：最後に見た場所は改札付近です。
4. **希望する対応**：落とし物として届いていないか確認していただけますか。

## 5. 会話例

**利用者：すみません。駅で財布をなくしてしまいました。**

**駅員：いつごろ、どのあたりでなくしましたか。**

**利用者：今日の午後三時ごろ、改札の近くで気付きました。**

**駅員：財布の特徴を教えていただけますか。**

**利用者：黒い二つ折りの財布です。**

## 6. 使い分け・注意点

* 「なくしました」は紛失した事実、「なくしてしまいました」は残念な気持ちを含むことがあります。
* 「確認してください」より「確認していただけますか」のほうが丁寧です。
* 緊急性が高い場合は、遠回しにせず、必要な情報を簡潔にはっきり伝えます。
* 個人情報や貴重品の情報を伝える場合は、相手や窓口が適切か確認しましょう。

## 7. 練習問題

### 問題1：トラブルの場面に合う表現を選びましょう。

1. 財布が見つからない：（財布をなくしました・財布を予約しました）
2. 機械が動かない：（故障しています・到着しています）
3. 相手に丁寧に確認を依頼する：（確認していただけますか・確認してくれ）

### 問題2：道に迷ったとき、助けを求める表現を一つ書きましょう。

### 問題3：トラブルを説明するときに伝える情報を三つ挙げましょう。

## 8. 解答・解説

### 問題1

1. 財布をなくしました
2. 故障しています
3. 確認していただけますか

### 問題2

例：すみません、駅までの行き方を教えていただけますか。

### 問題3

例：何が起きたか、いつ起きたか、どこで起きたか。必要に応じて現在の状況や希望する対応も伝えます。

## 9. まとめ

トラブル対応では、状況を順番に整理し、必要な情報を具体的に伝えることが重要です。丁寧な依頼表現と、緊急時に使う簡潔な表現の両方を練習しましょう。
