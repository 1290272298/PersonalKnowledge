# 家族・友人との会話

## 1. このテーマについて

家族や友人との会話では、誘い、承諾、断り、感謝、相談など、親しい関係で使う表現が多くあります。丁寧さを保ちながら、相手との距離に合った自然な言い方を身につけましょう。

## 2. 誘う・予定を聞く表現

* 今度、一緒に食事に行きませんか。
* 週末は何か予定がありますか。
* よかったら、映画を見に行きませんか。
* 何時ごろが都合いいですか。
* どこで待ち合わせましょうか。

## 3. 承諾・断りの表現

| 表現             | 意味・使い方        |
| -------------- | ------------- |
| ぜひ行きたいです       | 積極的に承諾する      |
| いいですね          | 賛成・同意を伝える     |
| その日はちょっと都合が悪くて | 柔らかく断る        |
| また今度誘ってください    | 次の機会を希望する     |
| 予定を確認してから連絡します | すぐに返事できないと伝える |

## 4. 感謝・謝罪・相談の表現

* 手伝ってくれてありがとう。
* 本当に助かりました。
* 遅れてごめんね。
* ちょっと相談したいことがあるんだけど。
* どうしたらいいと思う。

## 5. 会話例

**A：今度の日曜日、一緒に買い物に行かない？**

**B：いいね。何時ごろにする？**

**A：午前十一時はどう？**

**B：大丈夫。駅の改札前で待ち合わせよう。**

**A：分かった。楽しみにしているね。**

## 6. 使い分け・注意点

* 友人には「行かない？」「どう？」などの普通体がよく使われます。
* あまり親しくない相手には「行きませんか」「いかがですか」などの丁寧な表現を使います。
* 断るときは、理由を簡潔に伝え、必要に応じて別の日を提案します。
* 親しい相手でも、相手の都合や気持ちを尊重しましょう。

## 7. 練習問題

### 問題1：自然な返事を選びましょう。

1. A：土曜日に映画を見ませんか。B：（いいですね・失礼いたします）。
2. A：今日は都合が悪いです。B：（また今度誘ってください・おめでとうございます）。
3. A：手伝ってくれてありがとう。B：（どういたしまして・いただきます）。

## 8. 解答・解説

2. また今度誘ってください
3. どういたしまして

### 問題2

## 9. まとめ

親しい相手との会話では、誘い・承諾・断り・感謝などの表現を、相手との関係に合わせて使い分けましょう。
