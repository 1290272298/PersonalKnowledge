# 駅・電車・交通機関での会話

## 1. このテーマについて

![駅で行き先を尋ねる場面を描いたオリジナルイラスト](../.gitbook/assets/station-scene.svg)

駅や電車では、切符の購入、行き先の確認、乗り換え、遅延・運休への対応などの表現を使います。駅員への質問や車内放送でよく使われる語彙も覚えましょう。

## 2. 切符・行き先の確認

| 表現              | 意味・使い方      |
| --------------- | ----------- |
| 新宿までの切符を一枚ください  | 行き先と枚数を伝える  |
| 片道ですか、往復ですか     | 乗車券の種類を確認する |
| 何番線から出ますか       | 発車ホームを尋ねる   |
| この電車は東京駅に止まりますか | 停車駅を確認する    |
| どこで乗り換えればいいですか  | 乗換駅を尋ねる     |

## 3. 乗車・乗り換えの表現

* 次の駅で降ります。
* 二番線で乗り換えてください。
* 急行ではなく、各駅停車に乗ってください。
* この電車は目的地まで行きますか。
* 改札はどちらですか。

## 4. 遅延・運休に関する表現

| 表現            | 意味               |
| ------------- | ---------------- |
| 遅延しています       | 予定より運行が遅れている     |
| 運転を見合わせています   | 一時的に運行を停止している    |
| 運休になりました      | その便・列車の運行を取りやめた  |
| 振替輸送を行っています   | 別の交通機関などで代替輸送を行う |
| 運行状況を確認してください | 現在の運転情報を確認する     |

## 5. 会話例

**旅行者：すみません。この電車は上野駅に止まりますか。**

**駅員：はい、止まります。三つ目の駅です。**

**旅行者：ありがとうございます。乗り換えは必要ですか。**

**駅員：いいえ、この電車でそのまま行けます。**

## 6. 使い分け・注意点

* 「乗る」は乗り物に入る・利用すること、「降りる」は乗り物から出ることです。
* 「乗り換える」は別の路線や交通機関に移ることです。
* 「遅延」は予定より遅れること、「運休」は運行そのものを取りやめることです。
* 駅員に尋ねるときは「～はどこですか」「～に行きますか」が便利です。

## 7. 練習問題

### 問題1：意味に合う語を選びましょう。

1. 電車の到着が予定より遅れること：（遅延・運休）
2. 別の路線の電車に乗り直すこと：（乗り換え・乗車）
3. 列車の運行を取りやめること：（運休・到着）

### 問題2：会話を完成させましょう。

旅行者：この電車は東京駅に（　　　）ますか。 駅員：はい、止まります。

### 問題3：「遅延」と「運休」の違いを説明しましょう。

## 8. 解答・解説

### 問題1

1. 遅延
2. 乗り換え
3. 運休

### 問題2

止まり

### 問題3

「遅延」は運行するものの予定より遅れている状態、「運休」は予定していた列車や便の運行を取りやめることです。

## 9. まとめ

交通機関では、行き先・乗り場・乗り換え・運行状況を確認する表現が重要です。駅の案内表示や放送で使われる語彙も一緒に覚えましょう。
