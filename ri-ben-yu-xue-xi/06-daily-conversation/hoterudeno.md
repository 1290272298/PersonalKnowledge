# 旅行・ホテルでの会話

## 1. このテーマについて

旅行やホテルでは、チェックイン、設備の確認、荷物の預け入れ、観光案内などの表現を使います。希望や困っていることを丁寧に伝える練習をしましょう。

## 2. チェックイン・チェックアウト

| 表現             | 意味・使い方        |
| -------------- | ------------- |
| 予約している田中です     | 予約者の名前を伝える    |
| チェックインをお願いします  | 宿泊手続きを依頼する    |
| 朝食は何時からですか     | 朝食の時間を確認する    |
| チェックアウトは何時ですか  | 退室時間を確認する     |
| 荷物を預かっていただけますか | 荷物の一時預かりを依頼する |

## 3. 設備・サービスを確認する表現

* Wi-Fiは無料で利用できますか。
* 大浴場は何時まで使えますか。
* 部屋にタオルはありますか。
* 近くにコンビニはありますか。
* 駅までの行き方を教えていただけますか。

## 4. 困ったときの表現

* 部屋のエアコンが動きません。
* 鍵を部屋に置いたまま出てしまいました。
* もう一枚タオルをいただけますか。
* 荷物がまだ届いていないようです。

## 5. 会話例

**客：予約している鈴木です。チェックインをお願いします。**

**受付：かしこまりました。パスポートまたは身分証明書を拝見してもよろしいでしょうか。**

**客：はい、こちらです。**

**受付：ありがとうございます。朝食は一階のレストランで、午前七時から十時までです。**

**客：分かりました。ありがとうございます。**

## 6. 使い分け・注意点

* 「預ける」は一時的に相手に渡して保管してもらうことです。
* 「チェックイン」は宿泊開始の手続き、「チェックアウト」は退室・精算の手続きです。
* 依頼するときは「～していただけますか」を使うと丁寧です。
* 困ったことが起きたら、場所・状況・希望する対応を具体的に伝えましょう。

## 7. 練習問題

### 問題1：場面に合う表現を選びましょう。

1. 宿泊を開始する手続き：（チェックイン・チェックアウト）
2. 荷物を一時的に保管してもらう：（預かってもらう・返してもらう）
3. 部屋の設備が動かないと伝える：（動きません・動きました）

### 問題2：ホテルで使う丁寧な依頼表現を一つ書きましょう。

### 問題3：朝食の時間を尋ねる質問を作りましょう。

## 8. 解答・解説

### 問題1

1. チェックイン
2. 預かってもらう
3. 動きません

### 問題2

例：荷物を預かっていただけますか。

### 問題3

例：朝食は何時から何時までですか。

## 9. まとめ

ホテルでは、手続き・設備確認・依頼・トラブル対応の表現を覚えると安心です。希望や状況を具体的に伝え、必要な情報を確認しましょう。
