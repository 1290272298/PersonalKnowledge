# 06 日常会話

## 1. このカテゴリーについて

このカテゴリーでは、日常生活でよく出会う場面を想定し、自然な会話表現を学びます。挨拶、雑談、買い物、飲食店、交通、病院、電話、旅行、家族・友人との会話、トラブル対応を扱います。

## 2. 学習内容

| 場面      | 学習する内容             |
| ------- | ------------------ |
| 挨拶・自己紹介 | 時間帯の挨拶、初対面、自己紹介    |
| 雑談      | 話題の始め方、相づち、質問、共感   |
| 買い物     | 商品確認、試着、支払い、返品・交換  |
| 飲食店     | 入店、注文、追加依頼、会計      |
| 交通機関    | 切符、行き先、乗換、遅延・運休    |
| 病院・薬局   | 受付、症状説明、診察、薬の確認    |
| 予約・電話   | 名乗り、用件、予約変更、電話の終了  |
| 旅行・ホテル  | チェックイン、設備確認、荷物、観光  |
| 家族・友人   | 誘い、承諾、断り、感謝、相談     |
| トラブル対応  | 状況説明、助けの依頼、解決方法の確認 |

## 3. 会話の練習方法

1. 場面と話し手の関係を確認する。
2. 会話例を声に出して読む。
3. 丁寧体と普通体の違いを確認する。
4. 自分の名前・予定・希望に置き換えて会話を作る。
5. 相手役と自分役を交代して練習する。

## 4. 自然な会話にするポイント

* 相手との関係に合わせて丁寧さを調整する。
* 相づちや短い質問を使い、会話を一方通行にしない。
* 依頼や断りは、理由や希望を簡潔に添える。
* 日時・人数・場所・金額などの重要情報は、繰り返して確認する。
* 困ったときは、状況・原因・希望する対応を順番に伝える。

## 5. 自己確認

* [ ] 初対面で自然に自己紹介できる。
* [ ] 相づちや質問を使って雑談を続けられる。
* [ ] 店や飲食店で希望を丁寧に伝えられる。
* [ ] 駅やホテルで必要な情報を尋ねられる。
* [ ] 症状やトラブルの状況を具体的に説明できる。
* [ ] 相手との関係に合わせて表現を選べる。

## 6. まとめ

会話表現は、単語や文型を覚えるだけでなく、場面・相手・目的と一緒に練習することが大切です。会話例を自分の状況に置き換え、実際に声に出して使ってみましょう。
