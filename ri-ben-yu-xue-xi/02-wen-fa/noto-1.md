# 日本語の受身形と受身表現

## 日本語の受身形と受身表現

### 1. 受身形とは

受身形は、他人や物から何らかの動作を受けることを表す文法です。

中国語の「被」に相当します。

例：

* 私は先生に褒められました。
* この本は多くの人に読まれています。
* 弟は母に叱られました。

### 2. 動詞の受身形の作り方

#### 2.1 五段動詞

動詞の最後の音を「ア段」に変えて、「れる」を付けます。

| 辞書形 | 受身形  |
| --- | ---- |
| 書く  | 書かれる |
| 話す  | 話される |
| 読む  | 読まれる |
| 買う  | 買われる |
| 待つ  | 待たれる |
| 使う  | 使われる |

注意：「う」で終わる動詞は「わ」に変えます。

#### 2.2 一段動詞

「る」を取って「られる」を付けます。

| 辞書形 | 受身形   |
| --- | ----- |
| 食べる | 食べられる |
| 見る  | 見られる  |
| 褒める | 褒められる |
| 教える | 教えられる |

#### 2.3 不規則動詞

| 辞書形    | 受身形        |
| ------ | ---------- |
| する     | される        |
| 来る（くる） | 来られる（こられる） |

### 3. 受身形の活用

| 活用    | 書かれる    |
| ----- | ------- |
| 否定形   | 書かれない   |
| 過去形   | 書かれた    |
| 過去否定形 | 書かれなかった |
| 丁寧形   | 書かれます   |

例：

* この商品はよく使われます。
* 昨日、先生に褒められました。
* その情報はまだ公開されていません。

### 4. 直接受身

動作を受ける人や物を主語にする表現です。

**基本文型：**

A は B に ～られる。

例：

* 私は先生に褒められました。
* 彼は上司に注意されました。
* この建物は有名な建築家によって設計されました。

### 5. 間接受身

自分が直接動作を受けていなくても、他人の行動によって迷惑や影響を受けたことを表します。

例：

* 私は弟にケーキを食べられました。
* 私は雨に降られました。
* 彼は隣の人に夜遅くまで騒がれました。

### 6. 物や出来事を主語にする受身

ニュース、説明文、報告書などでよく使われます。

例：

* この建物は100年前に建てられました。
* 新しいサービスが発表されました。
* この小説は世界中で読まれています。

### 7. 「に」と「によって」の使い分け

| 表現   | 主な使い方                 | 例文                  |
| ---- | --------------------- | ------------------- |
| に    | 動作をする人を示す             | 私は先生に褒められた。         |
| によって | 動作の主体・行為者を示す（特に説明文など） | この作品は有名な画家によって描かれた。 |

### 8. 学習のポイント

* 五段動詞・一段動詞・不規則動詞の受身形を覚える。
* 直接受身と間接受身の違いを理解する。
* 受身文の主語と動作をする人を区別する。
* 「に」と「によって」の使い方を練習する。

### 9. まとめ

受身形は、誰かから受けた動作や影響を表す重要な文法です。

会話だけでなく、ニュースや説明文でもよく使われるため、活用ルールと文型をしっかり身につけましょう。

### 10. 練習問題

#### 問題1：正しい受身形を選びましょう。

1. 書く →（書かれる・書けられる）
2. 食べる →（食べられる・食べれる）
3. する →（される・しられる）
4. 来る →（来られる・来れる）

#### 問題2：文を受身形に変えましょう。

1. 先生は私を褒めました。
2. 多くの人がこの本を読みます。
3. 誰かが私の傘を持っていきました。

#### 問題3：「直接受身」と「間接受身」の違いを説明しましょう。

### 11. 解答・解説

#### 問題1

1. 書かれる：五段動詞は最後の音をア段に変えて「れる」を付けます。
2. 食べられる：一段動詞は「る」を取って「られる」を付けます。
3. される：「する」の受身形は不規則です。
4. 来られる（こられる）：「来る」の受身形は不規則です。

#### 問題2

1. 私は先生に褒められました。
2. この本は多くの人に読まれます。
3. 私は誰かに傘を持っていかれました。

#### 問題3

直接受身は、主語が動作を直接受ける表現です。間接受身は、他人の行動によって主語が迷惑や影響を受けたことを表します。
