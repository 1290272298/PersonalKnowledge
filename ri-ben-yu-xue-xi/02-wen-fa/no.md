# 日本語の疑問文・疑問詞

## 日本語の疑問文・疑問詞

### 1. 疑問文の基本

日本語では、文末に「か」を付けることで、丁寧な疑問文を作ることができます。

例：

* あなたは学生ですか。
* 日本語を勉強しますか。
* これはあなたの本ですか。

普通体では、文末のイントネーションを上げて質問することもあります。

例：

* 明日、行く？
* これは何？

### 2. 基本的な疑問詞

| 疑問詞        | 意味    | 例文            |
| ---------- | ----- | ------------- |
| 何（なに・なん）   | 什么    | これは何ですか。      |
| 誰（だれ）      | 谁     | あの人は誰ですか。     |
| どこ         | 哪里    | 駅はどこですか。      |
| いつ         | 什么时候  | いつ日本へ行きますか。   |
| どう         | 怎样    | 日本の生活はどうですか。  |
| どうして       | 为什么   | どうして遅れましたか。   |
| なぜ         | 为什么   | なぜ日本語を勉強しますか。 |
| どれ         | 哪一个   | あなたの傘はどれですか。  |
| どの         | 哪个    | どの本が好きですか。    |
| どんな        | 什么样的  | どんな音楽が好きですか。  |
| いくら        | 多少钱   | これはいくらですか。    |
| いくつ        | 几个、几岁 | りんごはいくつありますか。 |
| 何時（なんじ）    | 几点    | 今、何時ですか。      |
| 何曜日（なんようび） | 星期几   | 今日は何曜日ですか。    |

### 3. 何（なに）と何（なん）の使い分け

「何」は文脈や後ろに続く言葉によって読み方が変わります。

例：

* 何を食べますか。（なに）
* 何ですか。（なん）
* 何時ですか。（なんじ）
* 何人ですか。（なんにん）

### 4. 疑問詞を使った文型

#### ～はどこですか

場所を尋ねる表現です。

例：

* トイレはどこですか。
* 駅はどこですか。

#### ～はいつですか

時間や日程を尋ねる表現です。

例：

* 試験はいつですか。
* 会議はいつですか。

#### ～はどうですか

状態や感想を尋ねる表現です。

例：

* 日本の生活はどうですか。
* この料理はどうですか。

#### どうして～ですか

理由を尋ねる表現です。

例：

* どうして日本語を勉強していますか。
* どうして会社を休みましたか。

### 5. 疑問詞を使った会話

A：お名前は何ですか。

B：田中です。

A：どこに住んでいますか。

B：東京に住んでいます。

A：いつ日本語を勉強しますか。

B：毎晩、勉強します。

### 6. 練習問題

（　）に適切な疑問詞を入れてください。

1. あなたの名前は（　）ですか。
2. トイレは（　）ですか。
3. 日本へ行くのは（　）ですか。
4. これは（　）ですか。
5. この時計は（　）ですか。

### 7. まとめ

疑問詞を正しく使うことで、相手に必要な情報を自然に尋ねることができます。

疑問詞の意味と使い方を覚え、日常会話で積極的に使ってみましょう。

### 8. 解答・解説

1. 何：名前を尋ねるときに使います。
2. どこ：場所を尋ねるときに使います。
3. いつ：時間や時期を尋ねるときに使います。
4. 何：物や内容を尋ねるときに使います。
5. いくら：値段や金額を尋ねるときに使います。

※ 文脈によって「どちら」「どの」「どう」など、別の疑問詞が適切になる場合もあります。
