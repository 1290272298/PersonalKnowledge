# 日本語の逆接・譲歩表現

## 日本語の逆接・譲歩表現

### 1. 逆接・譲歩表現とは

逆接とは、前の内容から予想される結果と異なる内容を後ろに続ける表現です。

譲歩とは、ある事実や条件を認めたうえで、それとは異なる内容を述べる表現です。

### 2. 「～が」：基本的な逆接

前の内容と後ろの内容が対立することを表します。

**例文：**

* この店は高いですが、おいしいです。
* 日本語は難しいですが、面白いです。
* 行きたいですが、今日は時間がありません。

### 3. 「～けれども・～けど」：逆接・前置き

「が」と同じように逆接を表します。また、相手に何かを依頼したり、質問したりするときの前置きにも使われます。

**例文：**

* 雨が降っていますけれども、出かけます。
* すみませんが、もう一度説明していただけますか。
* 少し相談したいことがあるんですけど。

### 4. 「～のに」：予想外の結果

前の内容から予想される結果と、実際の結果が違うことを表します。

**接続：**

* 動詞普通形 ＋ のに
* い形容詞 ＋ のに
* な形容詞・名詞 ＋ なのに

**例文：**

* 一生懸命勉強したのに、試験に落ちました。
* 薬を飲んだのに、熱が下がりません。
* 今日は休日なのに、会社へ行きます。

### 5. 「～ても」：条件を認めた逆接

ある条件が成立しても、結果が変わらないことを表します。

**接続：**

* 動詞て形 ＋ も
* い形容詞（くて）＋ も
* な形容詞・名詞 ＋ でも

**例文：**

* 雨が降っても、試合を続けます。
* 忙しくても、毎日勉強します。
* 休日でも、仕事をすることがあります。

### 6. 「～にもかかわらず」：強い逆接

ある事実や条件があるのに、それと矛盾する結果になったことを表します。書き言葉や改まった表現でよく使います。

**例文：**

* 大雨にもかかわらず、多くの人が集まりました。
* 何度も注意したにもかかわらず、同じ間違いが起きました。
* 彼は病気にもかかわらず、仕事を続けました。

### 7. 「～一方で」：対照的な内容

2つの異なる側面や特徴を対比するときに使います。

**例文：**

* この仕事は大変な一方で、やりがいがあります。
* 都会は便利な一方で、生活費が高いです。
* インターネットは便利な一方で、危険もあります。

### 8. 逆接・譲歩表現の比較

| 表現       | 意味・特徴    | 例          |
| -------- | -------- | ---------- |
| ～が       | 基本的な逆接   | 高いですが、おいしい |
| ～けれども    | 逆接・前置き   | 行きたいけれども   |
| ～のに      | 予想外の結果   | 勉強したのに     |
| ～ても      | 条件を認めた逆接 | 雨が降っても     |
| ～にもかかわらず | 強い逆接     | 雨にもかかわらず   |
| ～一方で     | 対照・二つの側面 | 便利な一方で     |

### 9. 学習のポイント

* 「が」「けれども」は日常会話でもよく使う
* 「のに」は期待や予想に反する結果を表す
* 「ても」は条件に関係なく結果が変わらないことを表す
* 「にもかかわらず」は改まった文章で使われる
* 「一方で」は異なる側面を対比するときに使う

### 10. まとめ

逆接・譲歩表現を使うことで、予想と異なる結果や、対立する意見をより正確に伝えられます。

それぞれのニュアンスを理解し、会話や文章の中で適切に使い分けましょう。

### 11. 練習問題

#### 問題1：最も適切な表現を選びましょう。

1. 雨が降っていた（が・ので）、試合は予定どおり行われました。
2. 高い（けれども・だから）、この商品を買いました。
3. 忙しい（にもかかわらず・ために）、彼は最後まで手伝ってくれました。
4. 何度説明しても、彼は理解しなかった。（それでも・そのため）もう一度説明した。

#### 問題2：「逆接」と「譲歩」の違いを説明しましょう。

### 12. 解答・解説

#### 問題1

1. が：雨という状況に反して、試合が行われたことを表します。
2. けれども：価格が高いという事実と、購入したという結果を対比しています。
3. にもかかわらず：忙しいという条件を認めたうえで、予想外の行動を示します。
4. それでも：前の状況を受け入れながら、行動を続けたことを表します。

#### 問題2

「逆接」は前の内容から予想される結果と異なる内容をつなぎます。「譲歩」は前の事実や条件を認めたうえで、それでも成り立つ内容を続けます。
