# 02 文法

## 1. このカテゴリーについて

このカテゴリーでは、日本語の文を正しく理解し、自然な会話や文章を作るための文法を学びます。基本的な活用や助詞から始め、複文、敬語、話し手の判断・意志を表す表現まで段階的に学習します。

## 2. 学習目標

* 動詞・形容詞・名詞の活用を理解する。
* 助詞や文型の基本的な使い方を身につける。
* 条件・理由・目的・逆接など、文と文の関係を表せる。
* 敬語や依頼・許可・禁止など、場面に合った表現を選べる。
* 推量・判断・伝聞・引用など、話し手の立場を表現できる。
* 似た文型の意味やニュアンスを比較して使い分けられる。

## 3. 学習内容

| 分野       | 主なテーマ                      |
| -------- | -------------------------- |
| 基本文法     | 疑問文、授受表現、可能形、受身形、使役形、条件表現  |
| 活用・文型    | 推量・意志、形式名詞、複合助詞、補助動詞・アスペクト |
| 対人表現     | 敬語、依頼、許可、禁止、義務、必要          |
| 論理関係     | 比較、否定、原因・理由・結果、目的・手段、逆接・譲歩 |
| 文の構成     | 並列・列挙、伝聞・引用、文末表現、時間・順序     |
| 意味・ニュアンス | 限定・強調、付帯状況、比喩・例示、追加・累加     |
| 話し手の判断   | 経験・習慣、判断・確信、様態・推定、婉曲・断定回避  |
| 総合整理     | 文法項目の比較、複合問題、誤用の確認         |

## 4. おすすめの学習順序

1. 基本的な活用と文型を確認する。
2. 条件・理由・目的など、文の論理関係を表す文型を学ぶ。
3. 受身・使役・授受・敬語など、動作の方向や人間関係を表す文型を学ぶ。
4. 時間・順序・付帯状況・経験など、出来事の関係を表す文型を学ぶ。
5. 推量・判断・伝聞・婉曲など、話し手の考え方を表す文型を学ぶ。
6. 総合整理ページで、似た文型の違いを比較する。

## 5. 文型を覚えるときの確認事項

* **意味**：その文型が何を表すか。
* **接続**：動詞・形容詞・名詞のどの形に接続するか。
* **使う場面**：会話、文章、ビジネスなど、どの場面で使うか。
* **ニュアンス**：似た文型と比べて、どのような違いがあるか。
* **例文**：自分で例文を作り、自然な使い方を確認する。

## 6. 練習問題の進め方

問題を解いた後は、正解だけでなく、間違った選択肢がなぜ不自然なのかも確認しましょう。接続の形を間違えた場合は活用表に戻り、意味を間違えた場合は例文を比較して復習します。

## 7. 自己確認

* [ ] 文型の接続方法を説明できる。
* [ ] 似た文型の意味の違いを説明できる。
* [ ] 文脈に合う文型を選べる。
* [ ] 学んだ文型を使って自分の例文を作れる。
* [ ] 丁寧さや相手との関係に応じて表現を選べる。

## 8. まとめ

文法は、形だけを暗記するのではなく、意味・接続・使用場面をまとめて理解することが大切です。例文を読み、自分で文を作り、練習問題で確認するサイクルを繰り返して、自然で正確な日本語を身につけましょう。
