# 日本語の依頼・許可・禁止表現

## 日本語の依頼・許可・禁止表現

### 1. 依頼・許可・禁止表現とは

依頼表現は、相手に何かをしてもらいたいときに使います。

許可表現は、何かをしてもよいか確認したり、許可を与えたりするときに使います。

禁止表現は、相手に何かをしてはいけないと伝えるときに使います。

### 2. 「～てください」：依頼・指示

相手に何かをしてほしいときに使う基本的な依頼表現です。

**例文：**

* ここに名前を書いてください。
* もう一度説明してください。
* 少し待ってください。

### 3. 「～てくださいませんか」：丁寧な依頼

相手に何かをしてもらいたいときに、より丁寧に依頼する表現です。

**例文：**

* もう一度説明してくださいませんか。
* この資料を確認してくださいませんか。
* 少し手伝ってくださいませんか。

### 4. 「～てもらえませんか」：依頼・お願い

相手に何かをしてもらえるか、丁寧にお願いするときに使います。

**例文：**

* 荷物を運んでもらえませんか。
* この書類を確認してもらえませんか。
* 駅まで案内してもらえませんか。

### 5. 「～てもいい」：許可

何かをしても問題がないことや、許可されていることを表します。

**例文：**

* ここに座ってもいいです。
* このパソコンを使ってもいいです。
* 明日休んでもいいです。

### 6. 「～てもいいですか」：許可を求める

何かをしてもよいか、相手に確認するときに使います。

**例文：**

* 窓を開けてもいいですか。
* ここで写真を撮ってもいいですか。
* この資料を持って帰ってもいいですか。

### 7. 「～てはいけない」：禁止

何かをしてはならないことや、禁止されていることを表します。

**例文：**

* ここでタバコを吸ってはいけません。
* 授業中に携帯電話を使ってはいけません。
* この部屋に入ってはいけません。

### 8. 「～ないでください」：禁止・控えるように依頼

相手に何かをしないようにお願いするときに使います。

**例文：**

* ここで写真を撮らないでください。
* この資料を捨てないでください。
* 大きな声で話さないでください。

### 9. 依頼・許可・禁止表現の比較

| 表現         | 主な意味        | 例            |
| ---------- | ----------- | ------------ |
| ～てください     | 依頼・指示       | 書いてください      |
| ～てくださいませんか | 丁寧な依頼       | 説明してくださいませんか |
| ～てもらえませんか  | 依頼・お願い      | 手伝ってもらえませんか  |
| ～てもいい      | 許可          | 使ってもいい       |
| ～てもいいですか   | 許可を求める      | 座ってもいいですか    |
| ～てはいけない    | 禁止          | 入ってはいけない     |
| ～ないでください   | 禁止・控えるように依頼 | 忘れないでください    |

### 10. 間違いやすい表現

#### 「～てはいけない」と「～ないでください」

* ここに入ってはいけません：規則やルールとして禁止されていることを表します。
* ここに入らないでください：相手に入らないようにお願いする表現です。

#### 「～てもいい」と「～なくてもいい」

* 行ってもいい：行くことが許可されている。
* 行かなくてもいい：行く必要がない。

### 11. 学習のポイント

* 「～てください」は基本的な依頼を表す
* 「～てくださいませんか」は丁寧な依頼を表す
* 「～てもらえませんか」は相手へのお願いを表す
* 「～てもいい」は許可を表す
* 「～てもいいですか」は許可を求める
* 「～てはいけない」は禁止を表す
* 「～ないでください」は相手に控えるように依頼する

### 12. まとめ

依頼・許可・禁止表現を理解すると、相手に何かをお願いしたり、許可を求めたり、ルールや注意事項を伝えたりできるようになります。

それぞれの表現の丁寧さや使う場面の違いを理解し、状況に応じた自然な日本語を身につけましょう。

### 9. 練習問題

#### 問題1：場面に合う表現を選びましょう。

1. ここに座っても（いいですか・はいけませんか）。
2. この部屋では写真を撮って（もいいです・はいけません）。
3. 先生にもう一度説明して（いただけませんか・はいけません）。
4. 明日までに提出し（てください・ないでください）。

#### 問題2：依頼・許可・禁止に分類しましょう。

1. 入ってもいいです。
2. ここで食べないでください。
3. もう一度説明してください。

### 10. 解答・解説

#### 問題1

1. いいですか：行動の許可を求める表現です。
2. もいいです：写真撮影を許可する表現です。
3. いただけませんか：相手に丁寧に依頼する表現です。
4. てください：相手に提出を依頼する表現です。

#### 問題2

1. 許可
2. 禁止・制止
3. 依頼
