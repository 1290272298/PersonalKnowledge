# 日本語の伝聞・引用表現

## 日本語の伝聞・引用表現

### 1. 伝聞・引用表現とは

伝聞表現とは、他の人から聞いた情報や、何かを通して得た情報を伝える表現です。

引用表現とは、人の発言や自分の考えなどを、その内容に沿って伝える表現です。

### 2. 「～そうだ」：伝聞

他の人から聞いた情報を、そのまま伝えるときに使います。

**接続：**

動詞・い形容詞・な形容詞・名詞の普通形 ＋ そうだ

※ な形容詞・名詞の現在肯定形では「だそうだ」となります。

**例文：**

* 天気予報によると、明日は雨が降るそうです。
* 彼は来月、日本へ帰るそうです。
* この店の料理はおいしいそうです。

### 3. 「～らしい」：推量・伝聞

聞いた情報や状況から判断して、確かな情報ではないことを伝えます。

**例文：**

* 彼は来月結婚するらしいです。
* あの店は最近人気があるらしいです。
* 明日は雪が降るらしいです。

### 4. 「～と言う」：発言の引用

人が話した内容や、何かの情報を引用するときに使います。

**例文：**

* 先生は明日テストがあると言いました。
* 彼は日本へ行きたいと言っています。
* ニュースでは、物価が上がっていると言っていました。

### 5. 「～と思う」：自分の考え・意見

自分の意見や判断を表すときに使います。

**例文：**

* 日本語は面白いと思います。
* 彼はもう帰ったと思います。
* この方法が一番良いと思います。

### 6. 「～とのことだ」：改まった伝聞

人から聞いた情報や連絡事項を、改まった形で伝える表現です。

**例文：**

* 担当者は本日休みとのことです。
* 会議は午後3時からとのことです。
* 先方から、資料を再送するとの連絡がありました。

### 7. 「～によると」：情報源を示す

情報をどこから得たのか、その情報源を示すときに使います。

**例文：**

* 天気予報によると、明日は晴れるそうです。
* ニュースによると、電車が遅れているそうです。
* 調査結果によると、利用者が増えているそうです。

### 8. 伝聞・引用表現の比較

| 表現     | 意味・特徴      | 例        |
| ------ | ---------- | -------- |
| ～そうだ   | 聞いた情報を伝える  | 雨が降るそうだ  |
| ～らしい   | 不確かな情報・推量  | 人気があるらしい |
| ～と言う   | 発言や内容を引用する | 行きたいと言った |
| ～と思う   | 自分の考えを表す   | 良いと思う    |
| ～とのことだ | 改まった伝聞     | 休みとのことだ  |
| ～によると  | 情報源を示す     | ニュースによると |

### 9. 学習のポイント

* 伝聞の「そうだ」と様態の「そうだ」を混同しない
* 「らしい」は確実ではない情報や推量に使う
* 「と言う」は発言や内容を引用するときに使う
* 「と思う」は自分の意見や判断を表す
* 「とのことだ」はビジネスや改まった連絡でよく使う

### 10. まとめ

伝聞・引用表現を使うことで、情報源や発言者、自分の意見を明確に伝えられます。

それぞれの意味と使い方を理解し、会話や文章の中で適切に使い分けましょう。

### 11. 練習問題

#### 問題1：最も適切な表現を選びましょう。

1. 天気予報によると、明日は雨が降る（そうです・ようです）。
2. 彼は「明日行きます」と（言いました・そうです）。
3. ニュースでは、電車が運休する（とのことです・と言いました）。
4. 先生は明日試験がある（と・そう）話しました。

#### 問題2：「そうです」と「ようです」の違いを説明しましょう。

### 12. 解答・解説

#### 問題1

1. そうです：天気予報から得た情報を伝える伝聞表現です。
2. 言いました：発言内容を直接引用しています。
3. とのことです：ニュースなどから得た情報を伝えています。
4. と：発言内容を引用する「～と話しました」の形です。

#### 問題2

伝聞の「そうです」は人や情報源から聞いた内容を伝えます。「ようです」は状況や根拠から判断した推測を表すことが多く、接続も異なります。
