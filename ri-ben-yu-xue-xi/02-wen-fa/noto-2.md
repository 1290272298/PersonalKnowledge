# 日本語の使役形と使役表現

## 日本語の使役形と使役表現

### 1. 使役形とは

使役形は、他の人に何かをさせることを表す文法です。

主に次の意味があります。

* 強制：相手に何かをするように命じる。
* 許可：相手が何かをすることを認める。
* 誘発：ある出来事や感情を引き起こす。

例：

* 母は子供に野菜を食べさせました。
* 先生は学生を早く帰らせました。
* 彼の話は私を笑わせました。

### 2. 動詞の使役形の作り方

#### 2.1 五段動詞

動詞の最後の音を「ア段」に変えて、「せる」を付けます。

| 辞書形 | 使役形  |
| --- | ---- |
| 書く  | 書かせる |
| 話す  | 話させる |
| 読む  | 読ませる |
| 買う  | 買わせる |
| 待つ  | 待たせる |
| 帰る  | 帰らせる |

注意：「う」で終わる動詞は「わ」に変えます。

例：

* 先生は学生に作文を書かせました。
* 母は子供に部屋を掃除させました。

#### 2.2 一段動詞

「る」を取って「させる」を付けます。

| 辞書形 | 使役形   |
| --- | ----- |
| 食べる | 食べさせる |
| 見る  | 見させる  |
| 起きる | 起きさせる |
| 寝る  | 寝させる  |

例：

* 母は子供に野菜を食べさせました。
* 先生は学生に資料を見させました。

#### 2.3 不規則動詞

| 辞書形    | 使役形        |
| ------ | ---------- |
| する     | させる        |
| 来る（くる） | 来させる（こさせる） |

例：

* 先生は学生に発表をさせました。
* 母は弟を病院に来させました。

### 3. 使役形の文型

#### 3.1 人に何かをさせる

自動詞の場合、一般的に「人を」を使います。

**基本文型：**

A は B を ～させる。

例：

* 母は子供を学校へ行かせました。
* 先生は学生を立たせました。

#### 3.2 人に何かをさせる（他動詞）

他動詞の場合、一般的に「人に」を使います。

**基本文型：**

A は B に N を ～させる。

例：

* 母は子供に野菜を食べさせました。
* 先生は学生に作文を書かせました。

### 4. 使役形が表す意味

#### 4.1 強制

相手の意思に関係なく、何かをさせることを表します。

例：

* 先生は学生に宿題をさせました。
* 上司は部下を残業させました。

#### 4.2 許可・容認

相手が何かをすることを認める意味を表します。

例：

* 母は子供に一人で買い物をさせました。
* 今日は早く帰らせてください。

#### 4.3 感情や状態を引き起こす

人の感情や反応を引き起こすことを表します。

例：

* その映画は私を感動させました。
* 彼の冗談はみんなを笑わせました。

### 5. 使役形を使った重要表現

#### 5.1 ～させてください

自分が何かをする許可を求める表現です。

例：

* 今日は早く帰らせてください。
* 私に説明させてください。

#### 5.2 ～させてもらう

相手の許可を得て、何かをすることを表します。

例：

* 明日は休ませてもらいます。
* 今回は私に担当させてもらいます。

#### 5.3 ～させてあげる

相手のために何かをする機会や許可を与えることを表します。

例：

* 子供に好きなことをさせてあげます。
* 今日は友達に先に帰らせてあげました。

### 6. 使役形と受身形の違い

| 文法  | 意味         | 例文          |
| --- | ---------- | ----------- |
| 使役形 | 誰かに何かをさせる  | 母は子供に勉強させた。 |
| 受身形 | 誰かから動作を受ける | 私は先生に褒められた。 |

### 7. 学習のポイント

* 五段動詞・一段動詞・不規則動詞の使役形を覚える。
* 自動詞と他動詞による助詞の違いを理解する。
* 強制と許可の意味を文脈から判断する。
* 「～させてください」「～させてもらう」の使い方を練習する。

### 8. まとめ

使役形は、誰かに何かをさせることや、行動の許可を与えることを表す重要な文法です。

動詞の活用ルールと文型を理解し、場面に応じて自然に使えるようにしましょう。

### 9. 練習問題

#### 問題1：正しい使役形を選びましょう。

1. 書く →（書かせる・書けさせる）
2. 食べる →（食べさせる・食べらせる）
3. する →（させる・しさせる）
4. 来る →（来させる・来らせる）

#### 問題2：文を使役形に変えましょう。

1. 母は子供が野菜を食べます。
2. 先生は学生が発表します。
3. 上司は部下が残業します。

#### 問題3：「強制」と「許可」の使役表現の違いを説明しましょう。

### 10. 解答・解説

#### 問題1

1. 書かせる：五段動詞は最後の音をア段に変えて「せる」を付けます。
2. 食べさせる：一段動詞は「る」を取って「させる」を付けます。
3. させる：「する」の使役形は不規則です。
4. 来させる（こさせる）：「来る」の使役形は不規則です。

#### 問題2

1. 母は子供に野菜を食べさせます。
2. 先生は学生に発表させます。
3. 上司は部下を残業させます。

※ 自動詞・他動詞や文脈によって、「人を」「人に」の使い分けに注意しましょう。

#### 問題3

強制は相手の意思に関係なく行動をさせることです。許可は相手が行動することを認めることです。どちらの意味になるかは文脈で判断します。
