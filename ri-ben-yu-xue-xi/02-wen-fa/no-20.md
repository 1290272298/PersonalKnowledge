# 日本語の追加・累加表現

## 日本語の追加・累加表現

### 1. 追加・累加表現とは

追加・累加表現とは、すでに述べた内容に、別の情報や条件を付け加える表現です。

複数の特徴や事実を組み合わせて説明したり、ある内容にさらに別の内容を加えたりするときに使います。

### 2. 「～だけでなく」：追加・範囲の拡大

ある内容だけではなく、それ以外の内容も含まれることを表します。

**例文：**

* 彼は英語だけでなく、中国語も話せます。
* この店は料理だけでなく、サービスもいいです。
* 日本語だけでなく、日本の文化にも興味があります。

### 3. 「～ばかりでなく」：追加・累加

ある内容に加えて、さらに別の内容もあることを表します。

「～だけでなく」と似ていますが、やや改まった文章でもよく使われます。

**例文：**

* 彼は仕事が速いばかりでなく、正確です。
* この商品は品質がいいばかりでなく、価格も安いです。
* 彼女は日本語ばかりでなく、英語も流暢に話します。

### 4. 「～に加えて」：追加

すでにある内容に、さらに別の内容を付け加えることを表します。

**例文：**

* 経験に加えて、専門的な知識も必要です。
* 今月は仕事が忙しいことに加えて、出張もあります。
* 基本料金に加えて、追加料金がかかります。

### 5. 「～上に」：理由・特徴の累加

ある特徴や状況に、さらに別の特徴や状況を付け加えるときに使います。

多くの場合、同じ方向の評価や理由を重ねて説明します。

**例文：**

* この店は料理がおいしい上に、値段も安いです。
* 今日は寒い上に、風も強いです。
* 彼は親切な上に、仕事も丁寧です。

### 6. 「～のみならず」：追加・累加（硬い表現）

ある内容だけではなく、それ以外の内容も含まれることを表します。

「～だけでなく」よりも改まった表現で、書き言葉や公式な文章によく使われます。

**例文：**

* この問題は日本のみならず、世界中で注目されています。
* 彼は国内のみならず、海外でも活躍しています。
* この制度は学生のみならず、社会人も利用できます。

### 7. 「～も～も」：複数の対象を並べて追加

二つ以上の対象を並べ、どちらも同じ条件に当てはまることを表します。

**例文：**

* 彼は英語も日本語も話せます。
* この店は料理もサービスも素晴らしいです。
* 休日も平日も毎日勉強しています。

### 8. 追加・累加表現の比較

| 表現      | 主な意味        | 例               |
| ------- | ----------- | --------------- |
| ～だけでなく  | 追加・範囲の拡大    | 英語だけでなく中国語も話す   |
| ～ばかりでなく | 追加・累加       | 安いばかりでなく品質もいい   |
| ～に加えて   | 追加          | 経験に加えて知識も必要     |
| ～上に     | 特徴・理由の累加    | 安い上においしい        |
| ～のみならず  | 追加・累加（硬い表現） | 国内のみならず海外でも活躍する |
| ～も～も    | 複数の対象を並べる   | 英語も日本語も話す       |

### 9. 間違いやすい表現

#### 「～だけでなく」と「～に加えて」

* 日本語だけでなく、英語も勉強しています：日本語以外にも英語を勉強していることを表します。
* 日本語の勉強に加えて、英語も勉強しています：日本語の勉強を基本として、英語の勉強も追加していることを表します。

#### 「～上に」と「～に加えて」

* この店は安い上に、おいしいです：店の特徴を重ねて評価しています。
* 料金に加えて、送料も必要です：すでにある料金に、別の費用が追加されることを表します。

### 10. 接続方法

| 表現      | 接続方法                               |
| ------- | ---------------------------------- |
| ～だけでなく  | 名詞・動詞・形容詞の普通形＋だけでなく                |
| ～ばかりでなく | 名詞＋ばかりでなく、動詞・形容詞の普通形＋ばかりでなく        |
| ～に加えて   | 名詞＋に加えて、普通形＋ことに加えて                 |
| ～上に     | 動詞・イ形容詞の普通形＋上に、ナ形容詞＋な＋上に、名詞＋である＋上に |
| ～のみならず  | 名詞・動詞・形容詞の普通形＋のみならず                |
| ～も～も    | 名詞＋も＋名詞＋も                          |

### 11. 学習のポイント

* 「～だけでなく」はある内容に別の内容を追加する
* 「～ばかりでなく」は複数の特徴や事実を累加する
* 「～に加えて」はすでにある内容に別の内容を付け加える
* 「～上に」は特徴や理由を重ねて説明する
* 「～のみならず」は改まった場面で追加・累加を表す
* 「～も～も」は複数の対象が同じ条件に当てはまることを表す

### 12. まとめ

追加・累加表現を理解すると、複数の情報や特徴を組み合わせて、より詳しく説明できるようになります。

それぞれの表現の意味やニュアンス、使う場面の違いを理解し、日常会話やビジネスの文章で自然に使えるようにしましょう。

### 11. 練習問題

#### 問題1：文に合う追加・累加表現を選びましょう。

1. 彼は英語（だけでなく・しか）中国語も話せます。
2. 雨（に加えて・に対して）、風も強くなりました。
3. この店は料理が安い。さらに、サービス（も・しか）よい。
4. 彼女は仕事（のみならず・だけ）地域活動にも参加しています。

#### 問題2：「だけでなく」と「のみならず」の違いを説明しましょう。

### 12. 解答・解説

#### 問題1

1. だけでなく：英語に加えて中国語も話せることを表します。
2. に加えて：雨に風という情報を追加しています。
3. も：料理の安さに加えて、サービスのよさも示しています。
4. のみならず：仕事だけではなく地域活動にも参加することを表す、やや硬い表現です。

#### 問題2

どちらも追加を表します。「だけでなく」は会話・文章の両方で広く使い、「のみならず」はやや改まった文章や説明で使われることが多いです。
