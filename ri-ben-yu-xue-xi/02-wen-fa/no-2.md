# 日本語の推量・意志表現

## 日本語の推量・意志表現

### 1. 推量・意志表現とは

推量表現は、ある事柄について予測したり、可能性を考えたりするときに使います。

意志表現は、自分がこれから何かをしようと考えていることを表します。

### 2. 推量を表す文型

#### 2.1 ～でしょう

話し手が、ある事柄について確信に近い予測をするときに使います。

接続：

* 動詞・い形容詞の普通形 + でしょう
* な形容詞・名詞 + でしょう

例文：

* 明日は雨が降るでしょう。
* 彼はもう帰ったでしょう。
* この問題は難しいでしょう。
* 彼は学生でしょう。

#### 2.2 ～かもしれない

ある事柄が起こる可能性があることを表します。

接続：\
普通形 + かもしれない

例文：

* 明日は雪が降るかもしれません。
* 彼は今日来ないかもしれません。
* この店はもう閉まっているかもしれません。

#### 2.3 ～はずだ

何らかの根拠や理由から、当然そうなると考えるときに使います。

接続：

* 動詞・い形容詞の普通形 + はずだ
* な形容詞 + なはずだ
* 名詞 + のはずだ

例文：

* 彼はもう家に着いたはずです。
* この道をまっすぐ行けば、駅に着くはずです。
* 今日は日曜日だから、銀行は休みのはずです。

#### 2.4 ～ようだ・～みたいだ

見たり聞いたりした情報から、ある状況を推測するときに使います。

例文：

* 外は雨が降っているようです。
* 彼は疲れているみたいです。
* あの人は先生のようです。

### 3. 意志を表す文型

#### 3.1 ～つもりだ

自分が何かをする予定や意志を表します。

接続：\
動詞の辞書形・ない形 + つもりだ

例文：

* 来年、日本へ留学するつもりです。
* 今日はお酒を飲まないつもりです。
* 週末は家でゆっくりするつもりです。

#### 3.2 ～ようと思う

自分が何かをしようと考えていることを表します。

接続：\
動詞の意向形 + と思う

例文：

* 日本語をもっと勉強しようと思います。
* 明日から運動しようと思っています。
* 今年は旅行に行こうと思います。

#### 3.3 ～ことにする

自分の判断で何かを決めることを表します。

接続：\
動詞の辞書形・ない形 + ことにする

例文：

* 毎日30分勉強することにしました。
* 今日は出かけないことにします。
* 来月から新しい仕事を始めることにしました。

#### 3.4 ～ことにしている

自分で決めた習慣やルールを継続していることを表します。

例文：

* 毎朝7時に起きることにしています。
* 健康のために、毎日歩くことにしています。

### 4. 推量表現の比較

| 文型      | 意味・使い方    |
| ------- | --------- |
| ～でしょう   | 確信に近い予測   |
| ～かもしれない | 可能性がある    |
| ～はずだ    | 根拠に基づく確信  |
| ～ようだ    | 状況からの推測   |
| ～みたいだ   | 会話で使う推測表現 |

### 5. 意志表現の比較

| 文型       | 意味・使い方        |
| -------- | ------------- |
| ～つもりだ    | 予定・意志         |
| ～ようと思う   | これからしようと考えている |
| ～ことにする   | 自分で決定する       |
| ～ことにしている | 決めた習慣・ルール     |

### 6. 学習のポイント

* 推量と意志の違いを理解する。
* 「でしょう」と「かもしれない」の確信度の違いを覚える。
* 「はずだ」は根拠がある推測に使う。
* 「つもりだ」と「ようと思う」の使い方を比較する。
* 自分の予定や考えを日本語で表現する練習をする。

### 7. まとめ

推量・意志表現は、自分の予測や考え、これからの予定を伝えるために重要な文法です。

それぞれの文型の意味と使い方を理解し、会話や文章の中で自然に使えるように練習しましょう。

### 8. 練習問題

#### 問題1：文に最も適切な表現を選びましょう。

1. 空が暗いので、雨が降る（でしょう・つもりです）。
2. 明日は早く起きる（つもりです・はずです）。
3. 彼はもう家に着いた（はずです・ようと思います）。
4. 来年、日本へ留学しよう（と思っています・かもしれません）。

#### 問題2：次の表現が「推量」か「意志」か答えましょう。

1. 今日は忙しくなるかもしれない。
2. 毎日漢字を復習することにした。
3. 彼は会議に参加するはずだ。

### 9. 解答・解説

#### 問題1

1. でしょう：空の様子を根拠にした予測です。
2. つもりです：自分の予定や意志を表します。
3. はずです：状況や根拠から、到着していると判断しています。
4. と思っています：留学するという自分の考え・意志を表します。

#### 問題2

1. 推量：可能性を予測しています。
2. 意志・決定：自分で復習することを決めています。
3. 推量・確信：根拠に基づいて参加すると判断しています。
