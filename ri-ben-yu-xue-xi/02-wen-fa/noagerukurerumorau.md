# 日本語の授受表現（あげる・くれる・もらう）

## 日本語の授受表現（あげる・くれる・もらう）

### 1. 授受表現とは

授受表現は、物や行為を誰が誰に与えるか、誰から受け取るかを表す文法です。

日本語では、主に「あげる」「くれる」「もらう」の3つを使います。

### 2. あげる

自分や自分側の人が、相手に物を与えるときに使います。

**基本文型：**

A は B に N を あげる。

例文：

* 私は友達にプレゼントをあげました。
* 妹は母に花をあげました。
* 田中さんは先生に手紙をあげました。

### 3. くれる

相手が自分、または自分側の人に物を与えるときに使います。

**基本文型：**

A は 私（私側の人）に N を くれる。

例文：

* 友達は私に本をくれました。
* 先生は弟に辞書をくれました。
* 母は私に新しい服をくれました。

### 4. もらう

自分や自分側の人が、相手から物を受け取るときに使います。

**基本文型：**

A は B に／から N を もらう。

例文：

* 私は友達にプレゼントをもらいました。
* 妹は先生から本をもらいました。
* 彼は会社から記念品をもらいました。

### 5. 3つの表現の違い

| 表現  | 意味      | 視点      |
| --- | ------- | ------- |
| あげる | 给别人     | 给出方     |
| くれる | 别人给我方   | 接收方（我方） |
| もらう | 从别人那里得到 | 接收方     |

比較例：

* 私は田中さんに本をあげました。
* 田中さんは私に本をくれました。
* 私は田中さんに本をもらいました。

### 6. ～てあげる

自分が相手のために何かをしてあげることを表します。

例文：

* 友達に日本語を教えてあげました。
* 妹の宿題を手伝ってあげました。

### 7. ～てくれる

相手が自分のために何かをしてくれることを表します。

例文：

* 友達が駅まで迎えに来てくれました。
* 母がお弁当を作ってくれました。

### 8. ～てもらう

相手に何かをしてもらうことを表します。

例文：

* 先生に作文を直してもらいました。
* 友達に仕事を手伝ってもらいました。

### 9. 学習のポイント

* 「あげる」は与える側の視点で使う。
* 「くれる」は相手から自分側への行為を表す。
* 「もらう」は受け取る側の視点で使う。
* 「～てあげる」「～てくれる」「～てもらう」の違いを理解する。

### 10. まとめ

授受表現は、人と人との物や行為のやり取りを表す重要な文法です。

誰が与えるのか、誰が受け取るのかを意識しながら、正しく使い分けましょう。

### 11. 練習問題

#### 問題1：最も適切な表現を選びましょう。

1. 私は友達に誕生日プレゼントを（あげました・くれました）。
2. 友達が私に本を（あげました・くれました）。
3. 私は先生に作文を直して（もらいました・あげました）。
4. 母が私のために弁当を作って（くれました・もらいました）。

#### 問題2：文を完成させましょう。

1. 私は妹に日本語を教えて（　　　）。
2. 友達が駅まで迎えに来て（　　　）。
3. 私は先生に発音を確認して（　　　）。

#### 問題3：「あげる」「くれる」「もらう」の視点の違いを説明しましょう。

### 12. 解答・解説

#### 問題1

1. あげました：自分から友達へ物を渡す行為です。
2. くれました：相手から自分側へ物を渡す行為です。
3. もらいました：自分が先生の行為を受けたことを表します。
4. くれました：母が自分のために行った行為です。

#### 問題2

1. あげました
2. くれました
3. もらいました

#### 問題3

「あげる」は与える側から、「くれる」は相手から自分側への行為として、「もらう」は受け取る側から表現します。誰が誰のために行動したのかを確認して選びます。
