# 送り仮名・漢字と仮名の使い分け

## 1. 送り仮名とは

送り仮名は、漢字で書かれた語の後ろなどに付けるひらがなです。動詞や形容詞の活用部分を表し、読み方や意味を分かりやすくします。

例：

* 書く
* 読みます
* 高い
* 新しい

## 2. 動詞の送り仮名

| 辞書形 | 送り仮名 | 活用例        |
| --- | ---- | ---------- |
| 書く  | く    | 書きます、書いた   |
| 読む  | む    | 読みます、読んだ   |
| 食べる | べる   | 食べます、食べた   |
| 考える | える   | 考えます、考えた   |
| 始める | める   | 始めます、始めた   |
| 終わる | わる   | 終わります、終わった |

## 3. 形容詞の送り仮名

| 基本形 | 活用例          |
| --- | ------------ |
| 高い  | 高くない、高かった    |
| 新しい | 新しくない、新しかった  |
| 忙しい | 忙しくない、忙しかった  |
| 静かだ | 静かではない、静かだった |
| 便利だ | 便利ではない、便利だった |

い形容詞は「い」を含む部分が活用し、な形容詞は名詞を修飾するときに「な」を使います。

## 4. 漢字と仮名の使い分け

一般的には、意味の中心となる名詞や動詞の語幹などを漢字で書き、助詞・助動詞・活用語尾などを仮名で書きます。

例：

* 私は毎日日本語を勉強します。
* 新しい本を買いました。
* 友達と映画を見に行きます。

ただし、読みやすさや文体によって、漢字で書くか仮名で書くかが変わる語もあります。

## 5. 間違えやすい表記

| 正しい表記 | 間違えやすい表記 | ポイント              |
| ----- | -------- | ----------------- |
| 表す    | 表わす      | 一般的には「表す」を使う      |
| 現れる   | 現われる     | 一般的には「現れる」を使う     |
| 行う    | 行なう      | 一般的には「行う」を使う      |
| 申し込む  | 申込む      | 動詞では送り仮名を付ける形が一般的 |
| 受け付ける | 受付ける     | 動詞として使う場合の表記に注意   |

## 6. 学習のポイント

* 辞書形と活用形をセットで覚える。
* 漢字の部分と送り仮名の部分を区別する。
* 動詞・形容詞の活用を声に出して確認する。
* 表記に迷ったときは、辞書や公的な表記資料で確認する。

## 7. 練習問題

### 問題1：正しい表記を選びましょう。

1. （書く・書くう）
2. （新しい・新しイ）
3. （申し込む・申込む）を使って文を作る。
4. （行う・行なう）予定です。

### 問題2：送り仮名を含めて活用しましょう。

1. 書く → ます形
2. 食べる → た形
3. 高い → 否定形
4. 忙しい → 過去形

## 8. 解答・解説

### 問題1

1. 書く
2. 新しい
3. 申し込む
4. 行う

### 問題2

1. 書きます
2. 食べた
3. 高くない
4. 忙しかった

## 9. まとめ

送り仮名は、読み方や活用を正しく表すために重要です。辞書形だけでなく、活用した形も一緒に覚え、自然で読みやすい表記を身につけましょう。
