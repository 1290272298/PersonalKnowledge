# 04 漢字

## 1. このカテゴリーについて

このカテゴリーでは、漢字の形・意味・読み方・筆順・熟語を体系的に学びます。漢字一字を覚えるだけでなく、熟語や例文の中で正しく読めることを目指します。

## 2. 学習内容

| テーマ        | 学習する内容              |
| ---------- | ------------------- |
| 漢字学習の基本    | 字形、意味、読み、熟語、復習方法    |
| 部首・漢字の構成   | 部首の位置、意味の手掛かり、構成要素  |
| 音読み・訓読み    | 読み方の違い、熟語、例外的な読み    |
| 筆順・書き方     | 画数、止め・はね・払い、字形のバランス |
| 送り仮名       | 動詞・形容詞の表記と活用        |
| 二字熟語・四字熟語  | 熟語の構成、意味、使用場面       |
| JLPT N5～N1 | レベル別の漢字・熟語・文脈理解     |

## 3. 学習の進め方

1. 漢字の形と部首を確認する。
2. 基本的な意味と音読み・訓読みを調べる。
3. 熟語を二つ以上覚え、例文で使い方を確認する。
4. 筆順を見ながら書き、字形を確認する。
5. 練習問題を解き、読み間違いや意味の混同を記録する。
6. 翌日・数日後・一週間後に復習する。

## 4. レベル別の学習方針

* **N5・N4**：数字、時間、学校、生活、移動など、身近な漢字を中心に学ぶ。
* **N3**：社会、感情、判断、変化など、説明文で使われる漢字語彙を増やす。
* **N2**：論理、制度、評価、抽象概念に関する熟語を理解する。
* **N1**：論説・評論・専門的な文章に出る高度な語彙と細かな意味の違いを学ぶ。

掲載する漢字は学習用の選定例です。JLPTの公式な完全出題漢字一覧を示すものではありません。

## 5. 学習のポイント

* 一つの漢字に複数の読み方があることを意識する。
* 読み方は漢字単体ではなく、熟語や文脈で確認する。
* 似た形の漢字は、部首や画数を比較して覚える。
* 書く練習と読む練習を組み合わせる。
* 覚えた漢字を使って短い文を作る。

## 6. 自己確認

* [ ] 部首から漢字の意味を推測できる。
* [ ] 音読みと訓読みの違いを説明できる。
* [ ] 熟語の読み方を単語単位で覚えている。
* [ ] 送り仮名を正しく使える。
* [ ] 筆順と字形を確認しながら書ける。
* [ ] 学習した漢字を例文の中で理解できる。

## 7. まとめ

漢字は、字形・意味・読み・熟語・書き方を組み合わせて学ぶことが重要です。漢字を単独で暗記するだけでなく、語彙や文章の中で使える力を身につけましょう。
