# JLPT N1 高度漢字・語彙

## 1. 学習の目安

このページでは、学術的な文章、評論、報道、専門的な説明などで使われる高度な漢字・語彙を整理します。掲載内容は学習用の選定例であり、公式の完全な出題漢字一覧ではありません。

## 5. 重要語彙の意味と使い方

| 語彙 | 読み方   | 意味・使い方                  |
| -- | ----- | ----------------------- |
| 仮説 | かせつ   | 検証する前に立てる仮の説明           |
| 検証 | けんしょう | 根拠や資料を使って正しさを確かめること     |
| 妥当 | だとう   | 判断や方法に無理がなく適切であること      |
| 論拠 | ろんきょ  | 議論や主張を支える根拠             |
| 施策 | しさく   | 目的を達成するために実施する具体的な方策    |
| 是正 | ぜせい   | 誤りや不適切な状態を正しく直すこと       |
| 懸念 | けねん   | 悪い結果になる可能性を心配すること       |
| 顕著 | けんちょ  | 変化や特徴がはっきり現れていること       |
| 精緻 | せいち   | 細部まで非常に精密であること          |
| 卓越 | たくえつ  | 他より非常に優れていること           |
| 甚大 | じんだい  | 被害や影響などが非常に大きいこと        |
| 示唆 | しさ    | 直接言わずに、それとなく示すこと        |
| 含意 | がんい   | 表面に直接書かれていないが、内容に含まれる意味 |

## 6. 例文

* 調査結果を検証し、仮説が妥当かどうかを判断します。
* 新しい施策には一定の効果が見られましたが、費用面の懸念も残っています。
* 台風による被害は一部の地域で甚大でした。
* 筆者の発言は、制度の見直しが必要であることを示唆しています。
* この文章には、表面的な説明とは異なる含意があります。

## 7. 使い分け・注意点

* **仮説**は検証前の仮の説明、**結論**は検討や論証を経て導いた判断です。
* **妥当**は適切で無理がないこと、**正確**は事実や数値に誤りがないことです。
* **懸念**は心配や危惧、**問題**は解決や対応が必要な事柄を広く指します。
* **示唆**は何かを間接的に示すこと、**明示**ははっきり示すことです。
* 高度な漢字語彙は、前後の文脈や一緒に使われる動詞・名詞を確認しましょう。

## 8. 練習問題

### 問題1：読み方を書きましょう。

1. 仮説
2. 妥当
3. 論拠
4. 是正
5. 懸念
6. 顕著
7. 精緻
8. 示唆

### 問題2：意味に合う語彙を選びましょう。

1. 正しさを資料や根拠によって確かめること：（検証・懸念）
2. 不適切な状態を正しく直すこと：（是正・示唆）
3. 特徴や変化がはっきり現れていること：（顕著・妥当）
4. 直接言わずに、それとなく意味を伝えること：（示唆・検証）
5. 主張を支える根拠：（論拠・含意）

### 問題3：文に合う語彙を入れましょう。

1. 調査データを使って、仮説を（　　　）する。
2. 新制度の導入による費用の増加が（　　　）されている。
3. 事故による被害は非常に大きく、（　　　）なものとなった。
4. 文章の表面には書かれていない意味を（　　　）という。

### 問題4：次の語彙の違いを説明しましょう。

1. 「妥当」と「正確」
2. 「示唆」と「明示」
3. 「仮説」と「結論」

## 10. まとめ

N1レベルの漢字・語彙は、抽象的な概念や論理的な文章を理解するために重要です。漢字の読み方だけでなく、語彙の意味・ニュアンス・共起表現を確認し、論説文や報告文の中で正確に理解できるようにしましょう。
