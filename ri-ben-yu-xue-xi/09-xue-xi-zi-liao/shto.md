# 漢字・熟語復習シート

## 1. 漢字復習シートの目的

漢字復習シートは、字形・部首・画数・読み方・意味・熟語を整理し、漢字を単語や文章の中で使えるようにするための資料です。

## 2. 記録する項目

| 項目  | 記録内容        |
| --- | ----------- |
| 漢字  | 覚えたい漢字      |
| 部首  | 部首名・位置      |
| 画数  | 総画数         |
| 音読み | 音読みの例       |
| 訓読み | 訓読みの例       |
| 意味  | 基本的な意味      |
| 熟語  | 読み方と意味を含む単語 |
| 例文  | 熟語を使った短い文   |

## 3. 記入例

| 項目  | 内容                |
| --- | ----------------- |
| 漢字  | 改                 |
| 部首  | 攵（ぼくづくり）          |
| 音読み | カイ                |
| 訓読み | あらためる             |
| 意味  | 新しくする、直す          |
| 熟語  | 改善（かいぜん）、改正（かいせい） |
| 例文  | 作業手順を改善しました。      |

## 4. 熟語を使って覚える

一つの漢字について、二つ以上の熟語を覚えると、読み方や意味の広がりを理解しやすくなります。

例：

* 改：改善、改正、改札
* 率：比率、効率、確率
* 連：連絡、関連、連続

## 5. 復習の手順

1. 漢字を見て読み方を思い出す。
2. 意味を説明する。
3. 熟語を二つ以上挙げる。
4. 熟語を使って短い文を作る。
5. 似た形の漢字と比較する。

## 6. 練習問題

### 問題1：漢字「改」の音読みと訓読みを答えましょう。

### 問題2：「連」を使った熟語を二つ挙げましょう。

### 問題3：漢字を学ぶとき、読み方だけでなく熟語や例文を確認する理由を説明しましょう。

## 7. 解答・解説

### 問題1

音読みは「カイ」、訓読みは「あらためる」です。

### 問題2

例：連絡、関連、連続などです。

### 問題3

漢字は単語によって読み方や意味が変わるため、熟語や例文で確認すると実際の文章で理解しやすくなります。

## 8. まとめ

漢字は部首・画数・読み方・意味・熟語・例文をまとめて復習しましょう。漢字一字だけでなく、単語全体の読み方と意味を覚えることが大切です。
