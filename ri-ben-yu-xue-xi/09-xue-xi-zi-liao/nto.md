# 語彙ノート・復習方法

## 1. 語彙ノートの目的

語彙ノートは、知らなかった単語を記録するだけでなく、意味・読み方・使い方を整理し、後から思い出せるようにするためのものです。

## 2. 記録する項目

| 項目  | 記録する内容           |
| --- | ---------------- |
| 語彙  | 覚えたい単語           |
| 読み方 | ひらがなで読みを記録       |
| 品詞  | 名詞・動詞・形容詞・副詞など   |
| 意味  | 簡潔な説明            |
| 例文  | 自分で作った短い文        |
| 関連語 | 類義語・対義語・よく一緒に使う語 |
| 間違い | 読み間違い・使い方の誤り     |

## 3. 記録例

| 語彙 | 読み方   | 品詞      | 意味            | 例文             |
| -- | ----- | ------- | ------------- | -------------- |
| 改善 | かいぜん  | 名詞・する動詞 | 悪い状態をよくすること   | 作業手順を改善しました。   |
| 慎重 | しんちょう | な形容詞    | 注意深く行動する様子    | 慎重に確認してください。   |
| 延期 | えんき   | 名詞・する動詞 | 予定を後の日に変更すること | 会議は来週に延期されました。 |

## 4. 復習の方法

1. 語彙を見て、意味を隠して思い出す。
2. 読み方を声に出す。
3. 例文の空欄に語彙を入れる。
4. 類義語・対義語との違いを説明する。
5. 自分の経験に合わせた文を作る。

## 5. 復習スケジュール例

| タイミング | 復習内容         |
| ----- | ------------ |
| 学習当日  | 意味・読み方・例文を確認 |
| 翌日    | 意味を隠して思い出す   |
| 3日後   | 例文の穴埋めをする    |
| 1週間後  | 関連語と使い分けを確認  |
| 1か月後  | 総合テストで確認     |

## 6. 練習問題

### 問題1：語彙ノートに記録するとよい項目を四つ挙げましょう。

### 問題2：次の語彙を使って例文を作りましょう。

1. 改善
2. 慎重
3. 延期

### 問題3：意味を隠して思い出す練習が有効な理由を説明しましょう。

## 7. 解答・解説

### 問題1

例：語彙、読み方、品詞、意味、例文、関連語などです。

### 問題2

例：

1. 作業の流れを改善しました。
2. 契約内容を慎重に確認します。
3. 会議は来週に延期されました。

### 問題3

答えを見て確認するだけでなく、自分の記憶から情報を取り出す練習になるため、覚えた内容を使えるか確認できます。

## 8. まとめ

語彙ノートは、意味・読み方・品詞・例文・関連語をまとめて記録し、間隔を空けて思い出す練習をしましょう。
