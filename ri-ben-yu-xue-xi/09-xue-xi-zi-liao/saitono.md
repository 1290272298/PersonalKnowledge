# 辞書・学習サイトの活用

## 1. 辞書を使う目的

辞書や学習資料は、単語の意味を調べるだけでなく、読み方・品詞・用法・例文・類義語を確認するために使います。調べた内容をそのまま写すのではなく、自分で理解して短くまとめましょう。

## 2. 目的別の資料

| 調べたいこと | 参照する資料    | 確認する内容       |
| ------ | --------- | ------------ |
| 単語の意味  | 国語辞典・学習辞典 | 意味、品詞、用法     |
| 漢字     | 漢字辞典      | 読み、部首、画数、熟語  |
| 文型     | 文法辞典・文法教材 | 接続、意味、使用場面   |
| 自然な使い方 | 例文・用例     | 共起語、文脈       |
| 試験情報   | 試験実施機関の案内 | 試験日程、形式、注意事項 |

## 3. 調べた情報の確認方法

1. 一つの説明だけで判断せず、必要に応じて複数の資料を比較する。
2. 例文が自然な文脈で使われているか確認する。
3. 古い情報かどうか、更新日を確認する。
4. 試験情報や制度情報は、公式の案内を優先する。
5. 出典と確認日を自分のノートに記録する。

## 4. 情報を記録するテンプレート

| 項目       | 記録 |
| -------- | -- |
| 調べた語彙・文型 |    |
| 読み方・接続   |    |
| 意味       |    |
| 例文       |    |
| 参照した資料名  |    |
| 確認日      |    |
| 自分の理解    |    |

## 5. 注意点

* 検索結果の見出しだけで意味を判断しない。
* 自動翻訳だけに頼らず、日本語の例文で用法を確認する。
* 学習サイトの説明や例文を大量にコピーせず、自分の言葉で整理する。
* 画像・教材・音声などを利用する場合は、利用条件や著作権を確認する。
* JLPTの試験情報は、古い記事ではなく受験する回の案内を確認する。

## 6. 練習問題

### 問題1

漢字の読み方と部首を調べたいとき、どのような資料を使うとよいですか。

### 問題2

文型の使い方を確認するとき、意味以外に確認すべき項目を二つ挙げましょう。

### 問題3

学習資料をノートにまとめるとき、出典や確認日を記録する理由を説明しましょう。

## 7. 解答・解説

### 問題1

漢字辞典を使い、読み方・部首・画数・熟語などを確認します。

### 問題2

例：接続方法、使用場面、類似文型との違い、例文などです。

### 問題3

後から情報の正確さや新しさを確認でき、誤った情報や古い説明をそのまま使うことを防げるためです。

## 8. まとめ

辞書や学習資料は、目的に合わせて使い分け、意味・用法・例文を確認しましょう。調べた情報の出典と確認日を記録し、内容を自分の言葉で整理することが大切です。
