# JLPT模擬試験・時間管理

## 1. 模擬試験の目的

模擬試験は、学んだ知識を問題の中で使えるか確認し、時間配分や弱点を把握するために行います。点数だけでなく、間違えた原因を分析することが重要です。

## 2. 模擬試験の実施手順

1. 受験するレベルに合った問題を準備する。
2. 本番に近い環境を作り、途中で辞書や資料を見ない。
3. 時間を測り、最後まで解く。
4. 採点し、分野ごとの正答率を確認する。
5. 間違いの原因を分類する。
6. 次回までに改善する内容を決める。

## 3. 時間管理の考え方

試験の構成や時間は受験する回の案内で確認し、模擬試験では同じ条件を設定しましょう。

* 一問に時間をかけすぎない。
* 迷った問題には印を付け、後で戻る。
* 読解では設問に必要な情報を先に確認する。
* 最後に解答漏れやマークミスを確認する時間を残す。

## 4. 結果の記録シート

| 項目    | 記録      |
| ----- | ------- |
| 実施日   |         |
| 受験レベル |         |
| 文字・語彙 | 正答数／問題数 |
| 文法    | 正答数／問題数 |
| 読解    | 正答数／問題数 |
| 聴解    | 正答数／問題数 |
| 時間切れ  | あり・なし   |
| 次回の重点 |         |

## 5. 結果の分析方法

* 正答率が低い分野を特定する。
* 同じ種類の誤りが続いていないか確認する。
* 正解していても、根拠を説明できない問題を復習する。
* 時間切れの場合は、問題の優先順位や読む速度を見直す。

## 6. 練習問題

### 問題1

模擬試験を行う前に準備することを三つ挙げましょう。

### 問題2

正答率は高いのに時間切れになる場合、どのような点を見直すとよいですか。

### 問題3

間違えた問題を分析するとき、点数以外に記録すべき情報を二つ挙げましょう。

## 7. 解答・解説

### 問題1

例：問題冊子、解答用紙、時間を測る道具、静かな環境、受験レベルの確認などです。

### 問題2

一問にかける時間、迷った問題に戻る方法、設問の先読み、解答の優先順位などを見直します。

### 問題3

例：間違いの原因、分野、解答根拠、時間不足の有無、次回の対策などです。

## 8. まとめ

模擬試験は点数を確認するだけでなく、弱点と時間の使い方を分析するために活用しましょう。結果を次の学習計画に反映させることが大切です。
