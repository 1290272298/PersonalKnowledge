# 文法復習シートの作り方

## 1. 文法復習シートの目的

文法復習シートは、文型の接続・意味・使い方・似た表現との違いを一枚に整理し、短時間で復習できるようにするための資料です。

## 2. 記録する項目

| 項目   | 記録内容                |
| ---- | ------------------- |
| 文型   | 覚えたい文法              |
| 接続   | 動詞・形容詞・名詞のどの形に接続するか |
| 意味   | 中心的な意味・機能           |
| 使用場面 | 会話・文章・改まった表現など      |
| 例文   | 自分で作った例文            |
| 類似文型 | 似た意味の表現             |
| 注意点  | 誤用しやすい点             |

## 3. 記入例

| 項目   | 内容                          |
| ---- | --------------------------- |
| 文型   | ～ために                        |
| 接続   | 動詞辞書形＋ために／名詞＋の＋ために          |
| 意味   | 目的を表す                       |
| 使用場面 | 目標を達成するための行動を説明する           |
| 例文   | 日本語を上達させるために、毎日練習しています。     |
| 類似文型 | ～ように                        |
| 注意点  | 「ように」は能力や状態の実現を目標にする場合によく使う |

## 4. 似た文型を比較する方法

* 接続の形を比較する。
* 共通する意味と異なる意味を整理する。
* 使える主語・動詞・場面を確認する。
* 例文を並べ、置き換えられるか考える。

## 5. 復習の手順

1. 文型名を隠して、意味と接続を思い出す。
2. 接続を見て、正しい形を作る。
3. 例文の空欄に文型を入れる。
4. 類似文型との違いを説明する。
5. 自分の生活に関する例文を作る。

## 6. 練習問題

### 問題1：文法復習シートに必要な項目を五つ挙げましょう。

### 問題2：「～ために」を使って、目的を表す文を作りましょう。

### 問題3：文型を比較するときに確認すべき点を二つ挙げましょう。

## 7. 解答・解説

### 問題1

例：文型、接続、意味、使用場面、例文、類似文型、注意点です。

### 問題2

例：試験に合格するために、毎日勉強しています。

### 問題3

例：接続の形、意味の違い、使う場面、文体などです。

## 8. まとめ

文法は、接続・意味・使用場面・例文・類似表現を一つのシートにまとめると、違いを比較しながら効率よく復習できます。
