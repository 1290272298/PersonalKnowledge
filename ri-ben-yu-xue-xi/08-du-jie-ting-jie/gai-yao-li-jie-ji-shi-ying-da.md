# 概要理解・即時応答

## 1. 概要理解とは

概要理解では、会話や説明の細部だけでなく、全体の話題・目的・結論をつかみます。すべての単語を聞き取れなくても、話の流れから中心内容を判断しましょう。

## 2. 即時応答とは

即時応答では、相手の発言を聞き、場面や意図に合った自然な返事をすぐに選びます。質問への回答だけでなく、依頼・誘い・謝罪・確認への反応も練習します。

## 3. よくある発話の目的

| 発話の目的 | 表現例              | 自然な応答例          |
| ----- | ---------------- | --------------- |
| 依頼    | 窓を閉めてもらえますか      | はい、分かりました       |
| 誘い    | 一緒に昼食に行きませんか     | いいですね           |
| 謝罪    | お待たせして申し訳ありません   | いえ、大丈夫です        |
| 感謝    | 手伝ってくれてありがとう     | どういたしまして        |
| 確認    | 明日の会議は十時でよろしいですか | はい、そのとおりです      |
| 提案    | 先に資料を確認しましょうか    | そうしていただけると助かります |

## 4. 即時応答のポイント

* 相手が何を求めているかを判断する。
* 質問には直接答える。
* 依頼には承諾・断り・代案のいずれかで返す。
* 場面に合った丁寧さを選ぶ。
* 質問と関係のない返答を選ばない。

## 5. オリジナル練習問題

### 問題1：最も自然な返答を選びましょう。

1. A：この資料を確認していただけますか。\
   ア：はい、確認いたします。\
   イ：お誕生日おめでとうございます。
2. A：先ほどはありがとうございました。\
   ア：どういたしまして。\
   イ：いってらっしゃい。
3. A：明日の会議は午後二時からです。\
   ア：承知しました。\
   イ：お先に失礼します。
4. A：少し遅れそうです。\
   ア：分かりました。気を付けて来てください。\
   イ：いただきます。

### 問題2：会話全体の目的を答えましょう。

「A：明日の打ち合わせですが、開始時間を三時に変更できますか。\
B：三時ですね。問題ありません。\
A：ありがとうございます。では、三時に会議室でお願いします。」

この会話の目的は何ですか。

## 6. 解答・解説

### 問題1

1. ア：資料の確認依頼を受けています。
2. ア：感謝への自然な返答です。
3. ア：予定を聞いて了承しています。
4. ア：遅れるという連絡への配慮ある返答です。

### 問題2

打ち合わせの開始時間を午後三時に変更することです。

## 7. まとめ

概要理解では話題・目的・結論をつかみ、即時応答では相手の発話意図に合った返事を選びましょう。場面と相手との関係を意識することが大切です。
