# 説明文・論説文の読解

## 1. 説明文と論説文

* **説明文**：物事の仕組み、特徴、方法、事実などを分かりやすく説明する文章です。
* **論説文**：筆者の主張や意見を、理由や根拠を示しながら論理的に述べる文章です。

## 2. 読み取るべき要素

| 要素  | 確認する内容       |
| --- | ------------ |
| テーマ | 何について書かれているか |
| 主張  | 筆者が伝えたい意見    |
| 理由  | 主張の背景や理由     |
| 根拠  | データ、事実、具体例   |
| 対比  | 異なる考えや状況     |
| 結論  | 最終的に導かれる考え   |

## 3. よく使われる論理表現

* **理由**：なぜなら、というのは、～ため
* **逆接**：しかし、とはいえ、～ものの
* **追加**：さらに、そのうえ、また
* **対比**：一方、これに対して
* **結論**：したがって、以上のことから、つまり
* **例示**：例えば、具体的には

## 4. 読み方のポイント

* 最初と最後の段落から、テーマと結論を確認する。
* 「なぜなら」「そのため」などから理由と結果を整理する。
* 具体例と筆者の主張を混同しない。
* 「必ず」「一部」「多くの場合」など、範囲や程度を表す言葉に注意する。
* 選択肢の一部だけが本文と一致していても、全体の意味が違えば正解とは限らない。

## 5. 練習問題（オリジナル読解問題）

次の文章を読んで、質問に答えましょう。

「仕事の効率を高めるために、会議の回数を減らす企業がある。確かに、会議を減らせば作業時間を確保しやすくなる。しかし、情報共有や意思決定に必要な話し合いまでなくしてしまうと、関係者の認識がずれるおそれがある。重要なのは、会議を一律に減らすことではなく、目的が明確な会議を必要な人数で行い、決定事項を記録して共有することである。」

### 問題1

1. 筆者が取り上げているテーマは何ですか。
2. 会議を減らす利点は何ですか。
3. 会議を減らしすぎると、どのような問題が起こる可能性がありますか。
4. 筆者が重要だと考える会議の進め方は何ですか。

### 問題2

筆者の主張として最も適切なものを選びましょう。

* ア：会議はすべてなくすべきである。
* イ：会議の回数だけでなく、目的や共有方法を見直すべきである。
* ウ：会議にはできるだけ多くの人が参加すべきである。

## 6. 解答・解説

### 問題1

1. 仕事の効率を高めるための会議の見直しです。
2. 作業時間を確保しやすくなることです。
3. 関係者の認識がずれるおそれがあります。
4. 目的を明確にし、必要な人数で会議を行い、決定事項を記録・共有することです。

### 問題2

イ：筆者は会議を一律に減らすことではなく、目的と運営方法を見直すことが重要だと述べています。

## 7. まとめ

説明文では事実や仕組み、論説文では主張と根拠を意識して読みましょう。具体例に引っ張られず、筆者が最終的に何を伝えたいかを確認することが大切です。
