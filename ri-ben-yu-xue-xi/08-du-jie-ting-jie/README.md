# 08 読解・聴解

## 1. このカテゴリーについて

このカテゴリーでは、日本語の文章を正確に読み取る力と、会話・説明・講義などを聞き取る力を身につけます。単語を理解するだけでなく、文章や会話の目的、論理関係、重要情報を把握する練習をします。

## 2. 学習内容

| 分野   | テーマ        | 学習する力            |
| ---- | ---------- | ---------------- |
| 読解   | 文章構造       | 主題・要点・主張・根拠を整理する |
| 読解   | 説明文・論説文    | 筆者の意見と理由を読み取る    |
| 読解   | 情報検索       | 広告・案内から必要情報を探す   |
| 読解   | 長文・時間配分    | 段落構造と時間管理        |
| 聴解   | 基本的な聞き取り   | 場面・目的・重要情報をつかむ   |
| 聴解   | 課題理解       | 依頼・条件・期限・結論を聞く   |
| 聴解   | 概要理解・即時応答  | 会話の意図と自然な返答を判断する |
| 発音練習 | 音読・シャドーイング | 発音・リズム・聞き取りを改善する |

## 3. 読解の学習方法

1. 設問を先に確認し、探す情報を明確にする。
2. 段落ごとの役割と接続語を確認する。
3. 主張・理由・具体例・結論を整理する。
4. 答えの根拠となる箇所を本文から探す。
5. 選択肢と本文の内容が一致するか確認する。

## 4. 聴解の学習方法

1. 音声を聞く前に場面と設問を確認する。
2. 一回目は会話全体の流れをつかむ。
3. 二回目は数字・理由・変更・結論を確認する。
4. スクリプトで聞き取れなかった箇所を確認する。
5. 音読・リピート・シャドーイングで復習する。

## 5. 自己確認

* [ ] 文章の主題と段落ごとの要点を説明できる。
* [ ] 筆者の主張と具体例を区別できる。
* [ ] 案内文から日時・料金・条件を探せる。
* [ ] 会話の目的と最終的な決定を聞き取れる。
* [ ] 依頼・変更・理由・結論を整理できる。
* [ ] 短い文章を自然なリズムで音読できる。

## 6. まとめ

読解では本文の根拠を探し、聴解では会話の目的と結論をつかむことが大切です。間違えた問題は、知識不足・読み違い・聞き逃しなど原因を分類して復習しましょう。
