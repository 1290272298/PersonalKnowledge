# 課題理解・ポイント理解

## 1. 課題理解とは

課題理解では、会話や説明を聞き、何をする必要があるのか、どの条件を守るのか、最終的に何が決まったのかを理解します。

## 2. 聞き取るべき情報

| 情報 | 確認する内容      |
| -- | ----------- |
| 依頼 | 何をしてほしいか    |
| 担当 | 誰が行うか       |
| 期限 | いつまでに行うか    |
| 場所 | どこで行うか      |
| 条件 | どのような条件があるか |
| 変更 | 何が変わったか     |
| 結論 | 最終的にどうするか   |

## 3. 重要な表現

* ～までに提出してください：期限を示す。
* ～に変更になりました：予定や内容の変更を示す。
* ～を優先してください：対応順序を示す。
* ～は不要です：実施する必要がないことを示す。
* ～を確認したうえで：確認後に次の行動を行うことを示す。

## 4. 聞き取りの手順

1. 設問から、何を答える必要があるか確認する。
2. 依頼・担当・期限などのキーワードを意識して聞く。
3. 変更前と変更後を区別する。
4. 最後に決まった内容を確認する。
5. 複数の条件がある場合は、すべて満たすか確認する。

## 5. オリジナル聴解用スクリプト

**上司：資料の提出期限ですが、当初は金曜日でしたが、木曜日の午後五時に変更になりました。**

**担当者：承知しました。図表の確認は私が行い、本文の修正は佐藤さんにお願いする予定です。**

**上司：はい。まず図表を優先して確認してください。本文の修正は、その後で構いません。**

## 6. 練習問題

### 問題1：会話を聞いて答えましょう。

1. 資料の提出期限はいつに変更されましたか。
2. 図表の確認は誰が担当しますか。
3. 先に行う作業は何ですか。
4. 本文の修正はいつ行いますか。

### 問題2：変更前と変更後の情報を区別するために、どのような点に注意しますか。

## 7. 解答・解説

### 問題1

1. 木曜日の午後五時です。
2. 話している担当者です。
3. 図表の確認です。
4. 図表の確認が終わった後です。

### 問題2

「当初」「変更になりました」「現在」「最終的に」などの表現に注意し、変更前と変更後を分けて整理します。

## 8. まとめ

課題理解では、依頼・担当・期限・条件・変更・結論を整理します。聞いた情報をメモし、最終的な決定内容を正確に把握しましょう。
