# 動作・行動に関する語彙

## 動作・行動に関する語彙

### 1. 動作・行動に関する語彙とは

動作・行動に関する語彙とは、人や物が行う動き、活動、行為などを表す言葉です。

日常会話、学校、仕事など、さまざまな場面で使われます。

### 2. 基本的な動作を表す動詞

| 動詞  | 読み方 | 意味         |
| --- | --- | ---------- |
| 動く  | うごく | 移動する、動作する  |
| 止まる | とまる | 動作が終わる     |
| 歩く  | あるく | 足を使って移動する  |
| 走る  | はしる | 速く移動する     |
| 座る  | すわる | いすなどに腰を下ろす |
| 立つ  | たつ  | 体を起こして立つ   |
| 持つ  | もつ  | 手などで支える    |
| 置く  | おく  | ある場所に物を置く  |

**例文：**

* 毎朝、駅まで歩きます。
* ここに荷物を置いてください。
* 信号が赤になったので、車が止まりました。

### 3. 日常的な行動を表す動詞

| 動詞   | 読み方    | 意味          |
| ---- | ------ | ----------- |
| 起きる  | おきる    | 目を覚まして起床する  |
| 寝る   | ねる     | 眠る、横になる     |
| 食べる  | たべる    | 食事をする       |
| 飲む   | のむ     | 飲み物を口に入れる   |
| 洗う   | あらう    | 水などで汚れを落とす  |
| 掃除する | そうじする  | 汚れを取り除く     |
| 片付ける | かたづける  | 整理して元の場所に戻す |
| 準備する | じゅんびする | 必要なものを用意する  |

**例文：**

* 毎朝7時に起きます。
* 食事の前に手を洗います。
* 明日の会議の準備をしています。

### 4. 人との関わりを表す動詞

| 動詞  | 読み方  | 意味             |
| --- | ---- | -------------- |
| 会う  | あう   | 人と顔を合わせる       |
| 話す  | はなす  | 言葉で伝える         |
| 聞く  | きく   | 音や話を受け取る       |
| 教える | おしえる | 知識や方法を伝える      |
| 習う  | ならう  | 人から教えてもらう      |
| 伝える | つたえる | 情報や気持ちを知らせる    |
| 誘う  | さそう  | 一緒に何かをするように勧める |
| 手伝う | てつだう | 他の人の仕事を助ける     |

**例文：**

* 昨日、友達に会いました。
* 先生に日本語を教えてもらいました。
* 同僚の仕事を手伝いました。

### 5. 仕事や活動を表す動詞

| 動詞   | 読み方     | 意味          |
| ---- | ------- | ----------- |
| 働く   | はたらく    | 仕事をする       |
| 調べる  | しらべる    | 情報を確認する     |
| 確認する | かくにんする  | 正しいかどうか確かめる |
| 作成する | さくせいする  | 書類や資料などを作る  |
| 修正する | しゅうせいする | 間違いや問題を直す   |
| 報告する | ほうこくする  | 状況や結果を伝える   |
| 相談する | そうだんする  | 人に意見や助言を求める |
| 完了する | かんりょうする | すべて終わる      |

**例文：**

* 会議の資料を作成しました。
* 作業が完了したら、上司に報告します。
* 問題が発生したので、担当者に相談しました。

### 6. 意思や判断を表す動詞

| 動詞   | 読み方    | 意味            |
| ---- | ------ | ------------- |
| 考える  | かんがえる  | 頭を使って判断する     |
| 決める  | きめる    | 意思を固める        |
| 選ぶ   | えらぶ    | 複数から一つを取る     |
| 比べる  | くらべる   | 違いや同じ点を確認する   |
| 判断する | はんだんする | 状況を見て決める      |
| 予想する | よそうする  | これからのことを考える   |
| 信じる  | しんじる   | 正しいと思う        |
| 迷う   | まよう    | どちらにするか決められない |

**例文：**

* どの方法がよいか考えています。
* 自分で好きなものを選んでください。
* まだ決めていないので、少し迷っています。

### 7. 動作を表す類義語の違い

| 言葉   | 意味・使い方        |
| ---- | ------------- |
| 見る   | 目で対象を確認する     |
| 観る   | 映画や演劇などを楽しむ   |
| 聞く   | 音や話を耳で受け取る    |
| 聴く   | 音楽や話に注意を向けて聞く |
| 話す   | 言葉を使って伝える     |
| しゃべる | 日常的に話す、会話する   |
| 作る   | 一般的に物を生み出す    |
| 造る   | 建物や大きな物などを作る  |

**例文：**

* 映画を観ました。
* 音楽を聴きながら勉強します。
* 友達と楽しくしゃべりました。

### 8. 自動詞と他動詞の基本

動作を表す動詞には、自動詞と他動詞があります。

| 自動詞 | 他動詞 | 意味       |
| --- | --- | -------- |
| 開く  | 開ける | 開いた状態にする |
| 閉まる | 閉める | 閉じた状態にする |
| 始まる | 始める | 開始する     |
| 止まる | 止める | 動きを止める   |
| 入る  | 入れる | 中に移動する   |
| 出る  | 出す  | 外に移動させる  |

**例文：**

* ドアが開きました。
* ドアを開けてください。
* 会議が始まりました。
* 9時に会議を始めます。

### 9. 動作・行動に関する表現

| 表現      | 意味         |
| ------- | ---------- |
| 行動を起こす  | 何かを実際に始める  |
| 努力を続ける  | あきらめずに頑張る  |
| 仕事に取り組む | 仕事に集中して進める |
| 注意を払う   | 注意深く確認する   |
| 役割を果たす  | 自分の責任を実行する |
| 行動を改める  | 行動の仕方を変える  |

**例文：**

* 問題を解決するために行動を起こしました。
* ミスを防ぐために、細かい部分にも注意を払います。
* 自分の役割をしっかり果たします。

### 10. 間違えやすい動作・行動の語彙

| 言葉        | 違い                                   |
| --------- | ------------------------------------ |
| 聞く・尋ねる    | 「聞く」は音や情報を受け取ること。「尋ねる」は質問すること        |
| 教える・習う    | 「教える」は相手に伝えること。「習う」は相手から学ぶこと         |
| 直す・治す     | 「直す」は物や間違いを修正すること。「治す」は病気やけがを回復させること |
| 見つける・見つかる | 「見つける」は自分が発見すること。「見つかる」は発見されること      |
| 変える・変わる   | 「変える」は自分が変更すること。「変わる」は状態が変化すること      |

**例文：**

* 間違いを直してください。
* 病気を治すために病院へ行きました。
* 財布を見つけました。
* 財布が見つかりました。

### 11. 学習のポイント

* 動詞の意味だけでなく、使われる場面も一緒に覚える。
* 自動詞と他動詞の違いを理解する。
* 類義語の意味や使い方の違いを整理する。
* 「を」「に」「で」などの助詞と一緒に覚える。
* 日常生活や仕事の場面を想像しながら例文を作る。

### 12. まとめ

動作・行動に関する語彙は、日常会話からビジネスまで幅広く使われる重要な語彙です。

基本的な動詞だけでなく、類義語、自動詞・他動詞、動作に関する慣用表現も理解することで、より自然で正確な日本語を使えるようになります。

### 13. 練習問題

#### 問題1：最も適切な動詞を選びましょう。

1. 毎朝、駅まで（歩きます・置きます）。
2. 食事の前に手を（洗います・止まります）。
3. 会議の資料を（作成しました・迷いました）。
4. 分からないことがあれば、担当者に（相談します・走ります）。
5. 複数の案をよく（比べて・座って）から決めます。

#### 問題2：自動詞・他動詞の正しい組み合わせを選びましょう。

1. ドアが（開きました・開けました）。
2. 私が窓を（閉まりました・閉めました）。
3. 会議が九時に（始まりました・始めました）。
4. 担当者が作業を（止まりました・止めました）。

#### 問題3：次の言葉の違いを説明しましょう。

1. 「教える」と「習う」
2. 「直す」と「治す」
3. 「見つける」と「見つかる」

### 14. 解答・解説

#### 問題1

1. 歩きます：足を使って移動する動作です。
2. 洗います：水などで汚れを落とす動作です。
3. 作成しました：資料などを作ることです。
4. 相談します：相手に意見や助言を求めることです。
5. 比べて：複数のものの違いや共通点を確認することです。

#### 問題2

1. 開きました：「ドアが」を主語にする自動詞です。
2. 閉めました：「窓を」を目的語にする他動詞です。
3. 始まりました：「会議が」を主語にする自動詞です。
4. 止めました：「作業を」を目的語にする他動詞です。

#### 問題3

1. 「教える」は相手に知識や方法を伝えること、「習う」は相手から学ぶことです。
2. 「直す」は物や間違いを修正すること、「治す」は病気やけがを回復させることです。
3. 「見つける」は自分が何かを発見すること、「見つかる」は探していたものなどが発見されることです。
