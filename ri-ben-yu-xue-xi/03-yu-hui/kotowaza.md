# 慣用句・ことわざ

## 1. このテーマについて

慣用句は、複数の言葉が組み合わさり、全体で特別な意味を表す表現です。ことわざは、昔から伝えられてきた経験や教訓を短い言葉で表したものです。

文字どおりの意味だけでは理解できない表現も多いため、意味・使う場面・例文をセットで覚えましょう。

## 2. 主な分類・関連語彙

### 2.1 身体に関係する慣用句

| 表現                | 意味             | 例文                      |
| ----------------- | -------------- | ----------------------- |
| 頭が固い（あたまがかたい）     | 考え方が柔軟でない      | 彼は頭が固く、新しい方法を受け入れない。    |
| 頭に入れる（あたまにいれる）    | 知識や情報を覚える      | 注意事項を頭に入れておいてください。      |
| 手がかかる             | 世話や対応に時間・労力が必要 | この作業は手がかかります。           |
| 手を貸す（てをかす）        | 人を手伝う          | 引っ越しを手伝うので、少し手を貸してください。 |
| 目を通す（めをとおす）       | 全体をざっと読む       | 会議の前に資料に目を通してください。      |
| 目がない              | 大好きである         | 彼は甘い物に目がありません。          |
| 耳を傾ける（みみをかたむける）   | 注意して話を聞く       | 相手の意見に耳を傾けましょう。         |
| 腹が立つ（はらがたつ）       | 怒りを感じる         | 約束を守らないので腹が立ちました。       |
| 胸をなで下ろす（むねをなでおろす） | 安心する           | 無事だと分かり、胸をなで下ろしました。     |
| 顔が広い（かおがひろい）      | 知り合いが多い        | 彼女は地域で顔が広い人です。          |

### 2.2 感情・人間関係に関する慣用句

| 表現           | 意味            | 例文                 |
| ------------ | ------------- | ------------------ |
| 気が合う         | 性格や考え方が合う     | 二人は気が合うようです。       |
| 気になる         | 心配・関心がある      | 試験の結果が気になります。      |
| 気を配る（きをくばる）  | 周囲に注意する       | 周りの人に気を配って行動しましょう。 |
| 気が進まない       | する気になれない      | 雨なので、外出する気が進みません。  |
| 息が合う（いきがあう）  | 動作や考え方がぴったり合う | 二人は息が合ったプレーを見せました。 |
| 水に流す（みずにながす） | 過去のことを許して忘れる  | 今回の失敗は水に流しましょう。    |

### 2.3 行動・仕事に関する慣用句

| 表現             | 意味          | 例文                     |
| -------------- | ----------- | ---------------------- |
| 力を入れる（ちからをいれる） | 特に熱心に取り組む   | 今年は日本語の勉強に力を入れます。      |
| 力になる（ちからになる）   | 助けになる       | 先輩の助言が大きな力になりました。      |
| 口を出す（くちをだす）    | 他人のことに意見を言う | 人の仕事に必要以上に口を出さないでください。 |
| 口が堅い（くちがかたい）   | 秘密を他人に話さない  | 彼は口が堅いので安心です。          |
| 手を抜く（てをぬく）     | 必要な努力を省く    | 最後まで手を抜かずに取り組みましょう。    |
| 足を運ぶ（あしをはこぶ）   | わざわざ出かける    | 遠い店まで足を運びました。          |

### 2.4 ことわざ

| ことわざ          | 意味                       | 使う場面             |
| ------------- | ------------------------ | ---------------- |
| 石の上にも三年       | 辛抱強く続ければ成果が出る            | 勉強や仕事を続ける人を励ますとき |
| 急がば回れ         | 急ぐときほど安全で確実な方法を選ぶべき      | 慎重に進めるよう助言するとき   |
| 継続は力なり        | 続けることが大きな力になる            | 毎日の努力を評価するとき     |
| 七転び八起き        | 何度失敗しても立ち上がる             | 失敗から再挑戦するとき      |
| 猿も木から落ちる      | 得意な人でも失敗することがある          | 失敗した人を慰めるとき      |
| 備えあれば憂いなし     | 準備しておけば心配が少ない            | 事前準備の大切さを伝えるとき   |
| 二兎を追う者は一兎をも得ず | 二つを同時に得ようとして、どちらも失うことがある | 目標を絞るよう助言するとき    |
| 灯台下暗し         | 身近なことほど気づきにくい            | 近くにある答えを見落としたとき  |

## 3. 例文

**会議の前に資料に目を通し、分からない点を整理しておきました。** 意味：开会前我浏览了资料，并整理了不明白的地方。

**彼は失敗してもあきらめず、七転び八起きの精神で挑戦を続けています。** 意味：他即使失败也不放弃，以屡败屡战的精神继续挑战。

**急いで作業を進めるより、急がば回れで一つずつ確認したほうがよいです。** 意味：与其急着推进工作，不如稳扎稳打地逐项确认。

**長い間心配していましたが、問題が解決して胸をなで下ろしました。** 意味：我担心了很久，问题解决后终于松了一口气。

## 4. 使い分け・注意点

* 慣用句は、言葉を一つずつ直訳すると本来の意味と異なる場合があります。表現全体で意味を覚えましょう。
* 「目を通す」は全体をざっと読むことです。細部まで注意深く読む場合は「詳しく読む」「精読する」などを使います。
* 「手を貸す」は相手を助ける意味で、「手を抜く」は必要な努力を省く意味です。
* 「腹が立つ」は怒りを感じること、「胸をなで下ろす」は心配がなくなって安心することです。
* ことわざは、相手や場面によっては説教のように聞こえることがあります。使う相手と状況に注意しましょう。
* 会話では慣用句の一部を変えず、一般的な形で使うことが大切です。

## 5. 学習のポイント

* 慣用句は「身体の部分＋動詞」のように、共通する形でまとめて覚えます。
* ことわざは意味だけでなく、どんな場面で使えるかを考えます。
* 例文の主語や状況を変えて、自分の経験に合う文を作ってみましょう。
* 読解で見つけた表現は、前後の文から意味を推測してから辞書で確認します。

## 6. JLPTとの関連

慣用句・ことわざは、読解や語彙問題で文脈に合う意味を選ぶ際に役立ちます。中級以上では、文字どおりの意味と比喩的な意味の違いを理解し、文章全体から適切な解釈を判断する力が求められます。

## 8. 練習問題

### 問題1：慣用句の意味として最も適切なものを選びましょう。

1. 「資料に目を通す」
   * A. 資料を破る
   * B. 資料をざっと読む
   * C. 資料を作成する
2. 「彼は甘い物に目がない」
   * A. 甘い物が大嫌いだ
   * B. 甘い物を見つけられない
   * C. 甘い物が大好きだ
3. 「仕事に手を抜く」
   * A. 必要な努力を省く
   * B. 仕事を手伝う
   * C. 仕事を始める
4. 「胸をなで下ろす」
   * A. 怒る
   * B. 安心する
   * C. 驚く

### 問題2：文に合う慣用句・ことわざを選びましょう。

1. 毎日少しずつ勉強を続ければ、いつか成果が出る。→（継続は力なり・灯台下暗し）
2. 急いでいるが、安全のために順番に確認する。→（急がば回れ・二兎を追う者は一兎をも得ず）
3. 何度失敗しても、もう一度挑戦する。→（七転び八起き・猿も木から落ちる）
4. よく知っている人でも、時には間違える。→（猿も木から落ちる・備えあれば憂いなし）

### 問題3：空欄に適切な言葉を入れましょう。

1. 友人が困っていたので、引っ越しを手伝うために手を（　　　）。
2. 彼女は知り合いが多く、とても顔が（　　　）。
3. 相手の意見をよく聞くことを「耳を（　　　）」と言います。

## 9. 解答・解説

### 問題1

1. B：資料に目を通す＝全体をざっと読む。
2. C：～に目がない＝それが大好きである。
3. A：手を抜く＝必要な努力や作業を省く。
4. B：胸をなで下ろす＝心配がなくなり安心する。

### 問題2

1. 継続は力なり：続ける努力が成果につながるという意味です。
2. 急がば回れ：急ぐときほど確実な方法を選ぶべきだという意味です。
3. 七転び八起き：何度失敗しても立ち上がるという意味です。
4. 猿も木から落ちる：得意な人でも失敗することがあるという意味です。

### 問題3

1. 貸す（手を貸す）
2. 広い（顔が広い）
3. 傾ける（耳を傾ける）
