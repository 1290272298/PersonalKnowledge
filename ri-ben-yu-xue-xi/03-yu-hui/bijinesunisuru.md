# 仕事・ビジネスに関する基本語彙

## 仕事・ビジネスに関する基本語彙

### 1. 仕事・ビジネスに関する語彙とは

仕事・ビジネスに関する語彙とは、会社や職場、業務、会議、取引などの場面で使われる言葉です。

これらの語彙を理解することで、職場でのコミュニケーションやビジネス文書をより正確に理解できるようになります。

### 2. 会社・組織に関する語彙

| 単語  | 読み方    | 意味            |
| --- | ------ | ------------- |
| 会社  | かいしゃ   | 事業を行う組織       |
| 企業  | きぎょう   | 経済活動を行う組織     |
| 組織  | そしき    | 共通の目的を持つ集団    |
| 部署  | ぶしょ    | 会社内の部門        |
| 部門  | ぶもん    | 会社の業務上の区分     |
| 本社  | ほんしゃ   | 会社の中心となる事務所   |
| 支社  | ししゃ    | 本社以外の事業所      |
| 支店  | してん    | 本店以外の営業拠点     |
| 取引先 | とりひきさき | 取引を行う相手       |
| 関係者 | かんけいしゃ | ある業務や案件に関係する人 |

**例文：**

* 私は東京本社の営業部に所属しています。
* 新しい取引先との打ち合わせがあります。
* 関係者全員に資料を共有してください。

### 11. 学習のポイント

* 会社・組織・役職などの基本語彙を覚える。
* 業務・会議・報告など、場面ごとに語彙を整理する。
* ビジネス特有の動詞と名詞の組み合わせを覚える。
* 「報告・連絡・相談」など、職場で重要な表現を理解する。
* 類似する言葉は、意味や使用場面の違いに注意する。
* 実際のメールや会議で使われる表現と一緒に学習する。

### 12. まとめ

仕事・ビジネスに関する語彙は、職場で円滑にコミュニケーションを取るために欠かせないものです。

単語の意味だけでなく、会議・報告・契約などの具体的な場面と結び付けて学習し、実際の仕事で自然に使えるようにしましょう。

### 13. 練習問題

#### 問題1：最も適切な言葉を選びましょう。

1. 仕事の進み具合を確認することを（進捗・納期）確認と言います。
2. 商品や業務を注文することを（発注・受注）と言います。
3. 注文を受けることを（発注・受注）と言います。
4. 会議で話し合うテーマを（議題・議事録）と言います。
5. 必要な情報を関係者と一緒に利用できる状態にすることを（共有・承認）と言います。
6. 予定を後の日に変更することを（延期・前倒し）と言います。

#### 問題2：文に合う語彙を入れましょう。

1. 作業の進み具合を「（　　　）」と言います。
2. 商品や成果物を取引先に納めることを「（　　　）」と言います。
3. 会議の内容を記録した文書を「（　　　）」と言います。
4. 相手に仕事などを頼むことを「（　　　）」と言います。
5. 代金の支払いを求めることを「（　　　）」と言います。

#### 問題3：次の言葉の違いを説明しましょう。

1. 「発注」と「受注」
2. 「報告」と「連絡」と「相談」
3. 「納期」と「期限」

### 14. 解答・解説

#### 問題1

1. 進捗：仕事の進み具合を表します。
2. 発注：商品や業務を注文することです。
3. 受注：相手から注文を受けることです。
4. 議題：会議で話し合うテーマです。「議事録」は会議の内容を記録したものです。
5. 共有：情報や資料を関係者が利用できるようにすることです。
6. 延期：予定を後の日に変更することです。「前倒し」は予定を早めることです。

#### 問題2

1. 進捗
2. 納品
3. 議事録
4. 依頼
5. 請求

#### 問題3

1. 「発注」は注文する側の行為、「受注」は注文を受ける側の行為です。
2. 「報告」は結果や状況を伝えること、「連絡」は必要な情報を伝えること、「相談」は相手に意見や助言を求めることです。
3. 「納期」は商品や成果物を納める期限、「期限」は何かを行う必要がある最終時点を広く表します。
