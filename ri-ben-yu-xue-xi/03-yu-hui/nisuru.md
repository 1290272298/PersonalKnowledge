# 学校・教育に関する語彙

## 学校・教育に関する語彙

### 1. 学校・教育に関する語彙とは

学校・教育に関する語彙とは、学校生活や授業、試験、学習、進学などの場面で使われる言葉です。

これらの語彙を理解することで、学校での会話や教育に関する文章をより正確に理解できるようになります。

| 単語   | 読み方      | 意味             |
| ---- | -------- | -------------- |
| 学校   | がっこう     | 教育を受ける施設       |
| 小学校  | しょうがっこう  | 初等教育を行う学校      |
| 中学校  | ちゅうがっこう  | 中等教育を行う学校      |
| 高等学校 | こうとうがっこう | 高校             |
| 大学   | だいがく     | 高等教育を行う学校      |
| 大学院  | だいがくいん   | 大学卒業後に研究する教育機関 |
| 教室   | きょうしつ    | 授業を受ける部屋       |
| 図書館  | としょかん    | 本を読んだり借りたりする施設 |

### 11. 学習のポイント

* 単語の読み方・意味・使い方をセットで覚える。
* 学校や授業など、場面ごとに語彙を整理する。
* 名詞だけでなく、関連する動詞や形容詞も一緒に覚える。
* 試験・成績に関する語彙は、例文を通して使い方を理解する。
* 似た意味の単語は、使用場面の違いにも注意する。
* 学んだ語彙を使って、学校生活や学習経験を説明してみる。

### 12. まとめ

学校・教育に関する語彙は、学校生活や学習、試験、研究などの場面で必要となる重要な語彙です。

単語の意味を覚えるだけでなく、実際の授業や会話で使われる表現も一緒に学び、自然に使えるようにしましょう。

### 13. 練習問題

#### 問題1：最も適切な言葉を選びましょう。

1. 学校を終えて、その課程を修了することを（卒業・入学）と言います。
2. 授業の前に学習内容を確認することを（予習・復習）と言います。
3. 試験で必要な点数を取って通ることを（合格・不合格）と言います。
4. 大学で中心的に学ぶ分野を（専攻・成績）と言います。
5. 授業や行事に参加しないことを（欠席・出席）と言います。

#### 問題2：意味に合う語彙を書きましょう。

1. 授業で学んだ内容をもう一度学ぶこと：（　　　）
2. 学校に入ること：（　　　）
3. 答案の正誤を確認し、点数を付けること：（　　　）
4. 一定期間、学校を休むこと：（　　　）
5. 自分で学習すること：（　　　）

#### 問題3：次の言葉の違いを説明しましょう。

1. 「予習」と「復習」
2. 「講師」と「講義」
3. 「入学」と「進学」

### 14. 解答・解説

#### 問題1

1. 卒業：学校の課程を終えることです。
2. 予習：授業の前に学習することです。
3. 合格：試験などに通ることです。
4. 専攻：大学などで中心的に学ぶ分野です。
5. 欠席：授業や行事を休むことです。

#### 問題2

1. 復習
2. 入学
3. 採点
4. 休学
5. 自習

#### 問題3

1. 「予習」は授業の前に学ぶこと、「復習」は授業の後に学んだ内容をもう一度確認することです。
2. 「講師」は講義や授業をする人、「講義」は大学などで行われる授業です。
3. 「入学」は学校に入ること、「進学」は現在の学校を終えた後などに、より上級の学校へ進むことです。
