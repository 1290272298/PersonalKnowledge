# 抽象概念・思考に関する語彙

## 1. このテーマについて

抽象概念・思考に関する語彙は、意見を述べる、問題を分析する、原因を考える、将来を予測するなど、説明や議論でよく使われます。具体的な物の名前とは異なり、考え方や物事の関係を表す語が多いのが特徴です。

意味だけでなく、「分析する」「影響を与える」「可能性がある」のような自然な組み合わせも覚えましょう。

## 2. 主な分類・関連語彙

### 2.1 思考・検討に関する語彙

| 語彙 | 読み方  | 意味・使い方                 |
| -- | ---- | ---------------------- |

| 検討 | けんとう | よく調べ、実行するかどうか考えること     |
| 推論 | すいろん | 既知の情報から結論を導くこと         |
| 仮説 | かせつ  | 確認する前に立てる仮の説明          |
| 視点 | してん  | 物事を見る立場や角度             |
| 発想 | はっそう | 新しい考えを思いつくこと           |
| 前提 | ぜんてい | 話や判断の基礎となる条件           |

| 決定   | けってい      | 最終的に決めること          |
| 推測   | すいそく      | はっきり分からないことを想像すること |

| 客観的  | きゃっかんてき   | 個人的な感情に左右されないこと    |

### 2.4 可能性・程度に関する語彙

## 3. 例文

**複数の要因を分析し、問題が発生した背景を考察しました。** 意味：分析了多个因素，并考察了问题发生的背景。

**この仮説が妥当かどうか、別の視点からも検討する必要があります。** 意味：有必要从其他角度进一步研究这个假设是否合理。

**新しい制度は、利用者の行動に大きな影響を与える可能性があります。** 意味：新制度可能会对用户的行为产生很大影响。

**客観的な判断をするためには、十分な判断材料が必要です。** 意味：为了做出客观判断，需要充分的判断依据。

## 4. 使い分け・注意点

* 「分析」は要素に分けて調べること、「考察」は調べた内容をもとに意味や理由を深く考えることです。
* 「検討」は選択肢や方法をよく調べることです。「決定」は最終的に一つを選ぶことです。
* 「推測」は情報が不十分な状態で予想すること、「推論」は根拠を組み立てて結論を導くことです。
* 「原因」は直接的な理由を指すことが多く、「要因」は結果に関係する複数の条件の一つを指す場合があります。
* 「客観的」と「主観的」は対になる表現です。客観的な説明では、事実と個人の意見を区別します。
* 「具体的」は例や数字で説明できる状態、「抽象的」は一般的な考え方や概念を示す状態です。

## 5. 学習のポイント

* 「原因を分析する」「可能性を検討する」「影響を与える」のように、よく使う組み合わせで覚えます。
* 説明文を読むときは、「前提→要因→分析→判断→結論」の流れを意識します。
* 自分の意見を述べるときは、主観的な感想と客観的な事実を分けて表現しましょう。
* 抽象的な語彙は、身近な具体例と結びつけると覚えやすくなります。

## 6. JLPTとの関連

「原因」「影響」「傾向」「可能性」などは、説明文・評論文・意見文でよく使われる語彙です。中級以上では、似た意味の語の違いや、文中で示される論理関係を理解することが重要です。

## 7. まとめ

抽象概念・思考に関する語彙は、複雑な内容を整理し、筋道を立てて説明するために役立ちます。意味と用例を一緒に覚え、読解や作文で使えるようにしましょう。

## 8. 練習問題

### 問題1：最も適切な言葉を選びましょう。

1. データをいくつかの要素に分けて詳しく調べることを（分析・決定）と言います。
2. 実行するかどうか、よく調べて考えることを（検討・交付）と言います。
3. ある結果に関係する条件の一つを（要因・視点）と言います。
4. 個人の感情に左右されない判断は（客観的・主観的）な判断です。
5. まだ確認されていない仮の説明を（仮説・結果）と言います。

### 問題2：文に合う語彙を入れましょう。

1. 問題が起きた理由を詳しく調べるため、原因を（　　　）する。
2. 新しいサービスが利用者に与える（　　　）を調べる。
3. 将来そうなると予想されることを「（　　　）がある」と表現する。
4. 物事を見る立場や角度を「（　　　）」と言う。

### 問題3：次の言葉の違いを説明しましょう。

1. 「分析」と「考察」
2. 「推測」と「推論」
3. 「客観的」と「主観的」

## 9. 解答・解説

### 問題1

1. 分析：要素に分けて詳しく調べることです。
2. 検討：よく調べ、実行するかどうか考えることです。
3. 要因：結果に関係する条件や原因の一つです。
4. 客観的：個人的な感情に左右されないことです。
5. 仮説：確認する前に立てる仮の説明です。

### 問題2

1. 分析
2. 影響
3. 可能性
4. 視点

### 問題3

1. 「分析」は要素に分けて調べること、「考察」はその結果をもとに意味や理由を深く考えることです。
2. 「推測」は限られた情報から予想すること、「推論」は根拠を組み立てて結論を導くことです。
3. 「客観的」は個人の感情から離れて事実に基づくこと、「主観的」は個人の考えや感じ方に基づくことです。
