# Marketing Cloud 学习笔记

本知识库用于系统整理 Salesforce Marketing Cloud 的基础知识、产品功能、数据处理、开发技术、系统集成、邮件送达以及实际项目问题。

## 知识体系

| 章节 | 学习范围 |
|---|---|
| 01. 基础知识 | 产品体系、Business Unit、Subscriber / Contact、Key、Data Extension |
| 02. Email Studio | Content Builder、Email、发送配置、Tracking、订阅管理 |
| 03. Automation Studio | Automation、Schedule、SQL Query、Import、File Transfer、监控 |
| 04. Journey Builder | Journey、Entry Source、Activities、分支、等待、发布、监控 |
| 05. Contact Builder | Contact Model、Attribute Group、Data Designer、Relationship |
| 06. Personalization | Data Model、Catalog、Sitemap、Template、Content Zone、Campaign |
| 07. Development | SQL、AMPscript、SSJS |
| 08. API / Integration | REST API、SOAP API、OAuth、Data Extension API、Send API、系统集成 |
| 09. Deliverability | Bounce、Block Bounce、Held、Spam、List Detective、SPF / DKIM / DMARC |
| 10. 问题记录 | Subscriber、Email、Automation、Journey、Personalization、API 等实际问题 |

## 使用方式

- 按照目录顺序学习，也可以通过关键词查找特定功能。
- 每个主题尽量包含概念、原理、配置步骤、示例、注意事项和相关官方资料。
- 实际项目问题统一整理到第 10 章，避免将单次故障处理混入通用功能说明。
- 对尚未完成的主题保留目录，但明确区分“待补充”和“已完成”。

## 内容整理规范

### Official Knowledge
记录 Salesforce 官方定义、功能说明、适用范围和官方文档链接。

### Project Finding
记录在实际组织或项目中通过调查、测试确认的行为。需要注明环境前提，避免将个别环境结论误认为产品通用规则。

### 问题记录格式

1. **问题**：发生了什么问题？
2. **现象**：实际观察到了什么？
3. **调查过程**：进行了哪些确认和测试？
4. **原因**：最终确认的原因是什么？
5. **解决方案**：如何解决？
6. **结论**：最终得到什么结论？
7. **注意事项**：后续需要注意什么？
