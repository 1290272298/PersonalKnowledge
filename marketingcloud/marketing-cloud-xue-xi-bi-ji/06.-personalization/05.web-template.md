# 05. Web Template

## 学习目标
理解 Web Template 的用途、数据上下文、渲染逻辑和发布测试。

## 1. Web Template 是什么
Web Template 定义个性化内容如何生成和呈现。它通常包含 HTML、CSS、JavaScript 以及 Personalization 提供的模板上下文/数据引用。Template 与 Campaign、Content Zone 配合，将个性化内容显示到网站指定位置。

## 2. 主要组成
- Markup：内容结构。
- Styling：样式和响应式布局。
- Logic：根据受众或返回数据决定展示内容。
- Content / Catalog Data：模板使用的商品、文章或用户上下文。
- Interaction：曝光、点击等互动追踪。

具体模板语法和可用对象以当前 Personalization Template Editor / 开发文档为准。

## 3. 开发原则
1. 先定义展示目标和数据契约。
2. 对缺失字段设置安全默认值。
3. 对 URL 和文本进行适当编码/转义。
4. 避免依赖脆弱的 DOM 结构。
5. CSS 采用局部命名，避免污染网站全局样式。
6. 保证桌面、移动端和无推荐结果时的体验。
7. 不在模板中暴露 Secret 或敏感个人数据。

## 4. 测试
- 数据正常：展示正确内容。
- 数据为空：显示 fallback 或不渲染。
- 图片失效：有占位策略。
- 链接无效：不输出错误链接。
- 移动端：布局不溢出。
- 重复注入：页面不出现重复模块。
- 关闭/无同意状态：符合 Consent 规则。

## 5. 常见问题
- 模板未显示：检查 Campaign 状态、受众、Content Zone、模板错误和页面 Sitemap。
- 字段为空：检查 Catalog / User 数据字段名及数据上下文。
- 样式冲突：检查 CSS 选择器是否过于宽泛。
- 页面闪烁：检查模板加载时机、异步数据和隐藏占位策略。

## Checklist
- [ ] 数据字段契约明确
- [ ] 空值和错误状态有 fallback
- [ ] CSS/JS 不影响网站其他模块
- [ ] 移动端和主要浏览器已测试
- [ ] 互动事件和隐私规则正确
