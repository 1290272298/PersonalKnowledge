# 07. Campaign

## 学习目标
理解 Campaign 的受众、触发、优先级、模板、频控和上线监控。

## 1. Campaign 是什么
Personalization Campaign 将受众条件、决策策略、展示内容和投放位置组合起来，决定何时向哪些访客展示何种个性化体验。Campaign 类型和可用功能取决于渠道及数据集配置。

## 2. 常见组成
- Audience / Segment：谁可以看到。
- Trigger / Eligibility：何时符合展示条件。
- Content / Template：展示什么。
- Content Zone：展示在哪里。
- Priority / Ranking：多个 Campaign 冲突时的优先顺序。
- Frequency Cap：控制同一用户的展示频率（若该类型支持）。
- Goals / Stats：衡量曝光、点击和转化。

## 3. 设计流程
1. 明确业务目标和成功指标。
2. 定义受众及排除条件。
3. 选择 Campaign 类型和触发时机。
4. 绑定 Web Template 与 Content Zone。
5. 配置优先级、频控和开始/结束时间。
6. 用不同用户身份和页面类型测试。
7. 发布后观察曝光、点击、转化和错误。

## 4. 冲突与频控
多个 Campaign 可能竞争同一 Zone。需明确优先级、排他规则和默认体验。频控应考虑同一访客跨页面访问、匿名/已知身份关联和业务活动周期。

## 5. 常见问题
- Campaign 没有曝光：检查状态、日期、受众、Consent、Sitemap 和 Zone。
- 受众不准确：检查事件、用户属性和 Catalog 数据是否及时。
- 同一页面出现多个内容：检查优先级、Zone 和 Campaign 互斥规则。
- 点击有数据但无转化：检查转化事件是否采集、身份关联和归因窗口。

## Checklist
- [ ] 受众和排除条件正确
- [ ] Template 与 Zone 对应
- [ ] 优先级和频控明确
- [ ] 目标指标和归因口径明确
- [ ] 开始/结束时间与时区确认
- [ ] 上线监控与回退方案准备
