# 05. Contact Builder

## 案例 1：Journey 中找不到 DE 字段

### 问题
DE 中存在目标字段，但 Decision Split / Exit Criteria 中无法选择。

### 调查过程
1. 确认字段位于入口 DE 还是其他 DE。
2. 若要使用 Contact Data，检查该 DE 是否加入正确 Attribute Group。
3. 检查 Data Designer 关系是否连接到正确 Contact Key。
4. 检查字段类型、数据源和权限。
5. 若字段来自入口事件，确认使用 Journey Data 是否更合适。

### 原因
DE 中存在字段，不代表该字段自动成为 Contact Data。需要正确的模型关系；入口上下文与 Contact Model 关联属性也应区分。

### 解决方案
根据数据用途选择 Journey Data 或 Contact Data；需要 Contact Data 时，正确配置 Attribute Group 和关系，并验证实际 Contact。

## 案例 2：同一客户出现多个 Contact
检查不同系统的 Contact Key / Subscriber Key 是否一致，是否将 Email、手机号或临时 ID 当成主键。修复前评估历史发送、订阅和渠道数据，避免直接修改 Key 造成关联断裂。

## Checklist
- [ ] DE 与 Contact Model 的关系已区分
- [ ] Contact Key 一致
- [ ] Attribute Group 与关系已验证
- [ ] 一对多数据已定义选取规则
- [ ] 修改模型前已评估 Journey 依赖
