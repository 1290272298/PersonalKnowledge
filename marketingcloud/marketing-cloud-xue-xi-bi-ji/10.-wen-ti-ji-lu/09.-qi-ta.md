# 09. 其他

本页记录无法归入前述分类的 Marketing Cloud 问题，包括权限、BU、产品配置、UI 变化和外部系统限制。

## 案例 1：不同 BU 的可见性或权限不一致

### 调查过程
1. 确认当前登录用户、当前 BU 和目标资源所在 BU。
2. 检查角色、用户权限、共享设置和资源级权限。
3. 确认资源是否属于 Parent BU、Child BU 或共享 DE。
4. 使用最小必要权限验证。
5. 记录权限调整前后的差异。

### 注意
Parent BU 权限不等于所有 Child BU 的资源权限；Marketing Cloud Engagement 和 Personalization 的权限体系也不能直接互相替代。

## 案例 2：功能选项在 UI 中找不到
检查账号是否启用该产品/功能、用户权限、BU 上下文、当前版本和页面位置。参考官方文档时记录查阅日期，避免将旧版截图当成当前 UI 的唯一依据。

## 通用问题记录字段
| 字段 | 说明 |
|---|---|
| Product | Engagement / Personalization / CRM |
| BU / Dataset | 仅记录必要范围，敏感信息脱敏 |
| Feature | 相关功能 |
| UI / API Version | 版本或页面位置 |
| Symptom | 现象与错误文本 |
| Evidence | 日志、截图或请求 ID |
| Root Cause | 已确认原因 / 待确认 |
| Resolution | 处理与验证 |
| Prevention | 防复发措施 |

## Checklist
- [ ] 产品和 BU 上下文明确
- [ ] 权限与资源范围分别检查
- [ ] UI 版本和官方资料日期已记录
- [ ] 截图、日志和个人数据已脱敏
- [ ] 根因与推测分开记录
