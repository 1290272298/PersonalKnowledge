# 08. API / Integration

## 案例 1：OAuth API 调用返回 unauthorized / app blocked

### 调查过程
1. 确认错误发生在授权、Token 获取还是资源调用阶段。
2. 检查 Installed Package 状态和 API Integration 类型。
3. 检查 Client ID / Secret、Auth Base URI 和 Redirect URI（适用时）。
4. 检查 Scope、用户权限、IP 限制和账号安全策略。
5. 确认请求使用正确的 REST / SOAP Base URI。
6. 使用最小权限测试请求复现，并记录脱敏响应。

### 注意
OAuth 的 Redirect URI、IP Policy、App Authorization 和 API Scope 是不同控制点。不能仅修改某一项就假设问题已解决。

## 案例 2：API 请求成功但目标 BU 看不到数据
检查 Token 所属 MID、请求的 account_id / BU 上下文、共享 DE 权限和目标资源 Customer Key。Token 不会自动获得所有子 BU 的数据权限。

## 案例 3：超时后重复发送
先确认原请求是否已被受理，再按业务 ID 查询结果。对发送 API 和写入 API 设计幂等机制，避免超时重试导致重复消息或重复记录。

## Checklist
- [ ] 区分 OAuth / API 权限 / BU 上下文
- [ ] Base URI 来自当前 Package
- [ ] Secret 和 Token 已脱敏
- [ ] 超时和重试前确认操作结果
- [ ] 业务幂等 ID 已设计
