# 07. Data / SQL

## 案例 1：SQL 更新后目标 DE 记录数异常

### 调查过程
1. 确认 SQL Query Activity 的 Source / Target DE。
2. 检查 Data Action 是 Overwrite、Append 还是 Update。
3. 检查 JOIN 是否造成一对多扩行。
4. 检查 DISTINCT 是否掩盖真实重复问题。
5. 检查主键、NULL、日期边界和筛选条件。
6. 比较执行前后记录数和关键业务字段。

### 常见原因
- Overwrite 清除了原有目标数据。
- Append 重复插入。
- JOIN 键不唯一导致记录倍增。
- Target DE 主键或字段映射不正确。
- 日期过滤的时区/边界不一致。

## 案例 2：部分字段更新后原字段是否清空
对 DE Import、API Update 和 Personalization FTP Import，字段缺失行为可能不同。必须按具体产品、导入模式和字段映射做测试，不要跨产品类推。

## 案例 3：SQL Activity 超时
减少不必要列和全表扫描，尽早过滤，检查 JOIN 基数，避免并发覆盖同一 Target DE；必要时拆分步骤并验证每一步输出。

## Checklist
- [ ] Data Action 已确认
- [ ] JOIN 基数已验证
- [ ] 主键和字段映射正确
- [ ] 记录数前后有对账
- [ ] 日期和空值边界已测试
- [ ] 重跑不会重复或覆盖错误数据
