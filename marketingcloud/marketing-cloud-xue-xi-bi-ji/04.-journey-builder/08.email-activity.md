# 09. Email Activity

## 学习目标
掌握 Journey 中 Email Activity 的配置依赖、发送资格、测试和 Tracking 检查。

## 1. 功能与依赖
Email Activity 在 Journey 中向到达该节点的 Contact 发送邮件。邮件内容通常在 Content Builder 创建；发送配置需结合 Email Studio 中的 Send Classification、Sender Profile、Delivery Profile 等设置。

## 2. 发布前检查
| 项目 | 检查内容 |
|---|---|
| Email | 内容、动态内容、链接、默认值 |
| Audience / Entry | Contact Key、Email Address 和字段映射 |
| Send Classification | Commercial / Transactional 等业务分类是否正确 |
| Sender Profile | From Name / From Address |
| Delivery Profile | 发送 IP / Delivery 配置 |
| Subscriber Status | 是否具备发送资格，是否退订或 Held |
| Tracking | Open / Click 等跟踪设置 |
| Send Window | 发送时段、频率和业务时区 |

## 3. 配置步骤
1. 在 Journey Canvas 添加 Email Activity。
2. 选择已准备好的 Email 内容。
3. 检查相关发送配置及动态内容字段。
4. 检查入口 DE 与 Contact Key 的映射。
5. 用测试 Contact 验证个性化、链接和发送结果。
6. Activate 后观察发送与 Tracking 数据。

## 4. 重要注意事项
- Journey 入口人数不等于最终成功发送人数。
- Subscriber Status、Held、退订、抑制规则和发送资格会影响实际发送。
- 不要将 Email Address 当作 Contact Key 的替代品。
- Email 内容或发送配置修改时，确认 Journey 版本及已发布内容的引用关系。

## 5. 常见问题
**Contact 到达 Email Activity 但没有邮件？** 检查发送资格、订阅状态、Held/Bounce、发送配置、Email 是否有效，以及 Activity 执行记录。

**动态内容为空？** 检查字段是否在发送上下文中可用、字段名是否一致、空值默认值是否配置。

**Tracking 与预期不一致？** 检查发送日志、Tracking 设置、数据处理延迟及隐私代理影响。

## Checklist
- [ ] Email 内容与动态字段确认
- [ ] Sender / Delivery Profile 正确
- [ ] Send Classification 正确
- [ ] Contact Key 和订阅状态正确
- [ ] 测试邮件和链接检查完成
- [ ] 发送后监控 Send、Bounce、Open、Click、Unsubscribe
