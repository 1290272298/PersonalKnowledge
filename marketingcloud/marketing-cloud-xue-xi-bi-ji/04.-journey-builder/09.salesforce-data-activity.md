# 10. Salesforce Data Activity

## 学习目标
理解 Journey Builder 与 Sales / Service Cloud 的数据联动方式、权限依赖和常见排查点。

## 1. 功能概述
Salesforce Data / Sales and Service Cloud Activities 用于在 Journey 中使用 Salesforce CRM 相关事件或操作。可用 Activity、对象和操作取决于 Marketing Cloud Connect、连接用户、组织权限和账号配置。

不要将所有 Salesforce 集成功能都统称为一个 Activity；入口事件、CRM 数据活动和数据同步是不同机制。

## 2. 常见场景
- CRM 中记录创建或状态变化后触发营销旅程。
- 根据客户/商机数据执行分支。
- 在支持的 Activity 中更新 Salesforce 记录或执行 CRM 操作。

## 3. 设计前提
- Marketing Cloud Connect 已正确配置。
- 连接用户具有所需对象和字段权限。
- Salesforce Object、字段类型和必填字段确认。
- Contact / Lead 与 Marketing Cloud Contact Key 的映射一致。
- 处理 CRM API 限制、权限变更和同步延迟。

## 4. 实施步骤
1. 确认集成架构和可用 Activity。
2. 确认连接用户及对象/字段权限。
3. 确认 CRM 记录与 Contact Key 的映射。
4. 配置入口事件或相关 Activity。
5. 使用测试记录验证字段映射和执行结果。
6. 监控 CRM 与 Marketing Cloud 两侧日志。

## 5. 常见问题
- 找不到对象/字段：检查连接用户权限、对象可用性、字段级安全和同步配置。
- Contact 关联错误：检查 Contact Key 映射，避免 Email、CRM ID、Subscriber Key 混用。
- 更新失败：检查必填字段、记录锁定、权限和 API 限制。
- 数据延迟：确认同步机制与事件触发方式，不要假定 CRM 更新后所有 Contact Data 立即刷新。

## Checklist
- [ ] Marketing Cloud Connect / 集成已验证
- [ ] 连接用户权限最小化且足够
- [ ] 对象、字段、Contact Key 映射正确
- [ ] 失败和重试机制明确
- [ ] 两侧日志和负责人明确
