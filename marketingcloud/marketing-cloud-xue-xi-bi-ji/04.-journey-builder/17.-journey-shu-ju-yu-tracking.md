# 17. Journey 数据与 Tracking

## 学习目标
区分 Journey 执行数据与消息 Tracking，理解常见指标口径和数据分析限制。

## 1. 两类数据
- Journey 数据：入口、Activity、路径、退出和 Goal 的执行信息。
- 消息 Tracking：Email / SMS 等消息发送后的 Send、Bounce、Open、Click、Unsubscribe 等事件。

两者回答的问题不同：Journey 数据说明 Contact 走到哪里；Tracking 说明消息发生了什么。

## 2. 常见指标
| 指标 | 解释 | 注意事项 |
|---|---|---|
| Entry | 进入旅程的 Contact / 事件数量 | 重复进入时需明确口径 |
| Activity | 到达或完成节点的数量 | 不同节点口径可能不同 |
| Sent | 发送处理记录 | 不等于收件箱已送达 |
| Bounce | 退信 | 需区分硬退信/软退信 |
| Open | 像素触发记录 | 受隐私代理影响 |
| Click | 链接点击记录 | 可能受安全扫描影响 |
| Unsubscribe | 退订事件 | 需要及时抑制后续营销发送 |
| Goal | 达成目标的 Contact | 按目标过滤器和评估机制统计 |

## 3. 分析示例
```
Journey Entry 10,000
Email Activity 到达 9,800
Send 9,700
Click 1,200
Goal 300
```
这些数字仅为示例。分析前先明确每个指标的统计范围、时间窗口、去重方式和分母。

## 4. 归因注意
- Open Rate 不是可靠的真实阅读率。
- Click 可能包含自动扫描，需要结合业务转化事件。
- 同一 Contact 可重复进入 Journey，不能直接用 Entry 事件数作为独立人数。
- Goal 统计与外部订单系统 KPI 可能存在时间差和口径差异。

## 5. 排查方式
按 Journey Version、Contact Key、Activity、Send Job / Tracking 事件和业务 Event ID 建立关联。注意权限与数据保留周期，必要时将关键指标沉淀到数据仓库或报表系统。

## Checklist
- [ ] Journey 指标与 Tracking 指标分开解释
- [ ] 指标分母和去重口径明确
- [ ] Open / Click 的局限已告知业务
- [ ] Goal 与外部业务转化数据对账
- [ ] 数据保留、权限和导出方式明确
