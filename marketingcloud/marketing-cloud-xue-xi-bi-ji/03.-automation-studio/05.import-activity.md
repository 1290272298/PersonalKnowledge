# 05. Import Activity（Data Copy or Import）

## 1. 学习目标
理解 Import Activity 如何将文件或其他来源的数据写入 List / Data Extension，能够配置 File Location、文件名 Pattern、字段映射和导入 Data Action。

## 2. Import Activity 是什么
Automation Studio 中的 Data Copy or Import Activity（旧称 Import File）用于将外部文件或受支持的数据源导入 Subscriber List 或 Data Extension。它通常使用可复用的 Import Definition。

## 3. 典型导入流程
    上游系统
       ↓
    CSV / TXT
       ↓
    FTP / SFTP
       ↓（如文件加密或压缩）
    File Transfer → Safehouse
       ↓
    Import Activity
       ↓
    Target Data Extension

File Transfer 与 Import 是不同任务：前者准备文件，后者读取文件内容并写入目标数据对象。

## 4. 导入前准备
- 确认文件来源、目录和文件名 Pattern。
- 确认分隔符、Header、字符编码和日期格式。
- 确认目标 DE 的字段名称、类型、长度和主键。
- 确认文件是否有空行、重复 Key、非法字符或缺少字段。
- 明确重复运行同一文件时的处理策略。

示例 CSV：
    SubscriberKey,EmailAddress,Status
    C0001,member1@example.com,Active
    C0002,member2@example.com,Active

示例数据仅用于说明格式，不可作为真实收件人资料。

## 5. 关键配置项
| 配置 | 说明 | 检查点 |
|---|---|---|
| File Location | 文件所在位置 | 目录和权限是否正确 |
| File Naming Pattern | 文件名匹配规则 | 是否与上游文件一致 |
| File Type / Delimiter | 文件类型和分隔符 | CSV / TXT、逗号或 Tab |
| Header | 是否包含标题行 | 是否正确跳过或映射 |
| Character Encoding | 字符编码 | 日文 CSV 常需确认 UTF-8 等编码 |
| Date Format | 日期解析格式 | 与文件中的实际格式一致 |
| Destination | 导入目标 | 目标 DE / List 是否正确 |
| Mapping | 字段映射方式 | Header / Ordinal / Manual |
| Data Action | 导入时数据处理方式 | 与业务更新规则一致 |

## 6. Data Action
| Data Action | 主要含义 |
|---|---|
| Add Only | 只新增记录；已存在的主键可能导致冲突 |
| Update Only | 只更新目标中已存在的记录 |
| Add and Update | 更新匹配记录，并新增不存在的记录 |
| Overwrite | 覆盖目标数据；执行前必须确认目标范围和保留需求 |

实际可选项会受导入目标类型影响。不要将 Import 的 Data Action 与 SQL Query Activity 的 Data Action 混为一谈。

## 7. 字段映射方式
- Map by Header Row：根据文件 Header 名称映射。
- Map by Ordinal：按列顺序映射；文件列顺序改变可能导致错列。
- Map Manually：手动指定源列与目标字段关系。

如果上游文件列顺序可能变化，优先考虑 Header 映射并验证 Header 名称；若没有 Header，必须固定列顺序并纳入接口契约。

## 8. 实际操作：创建 Import Definition
1. 在 Automation Studio → Activities 创建 Data Copy or Import Activity。
2. 选择文件 Location 和文件名 Pattern。
3. 配置分隔符、Header、编码和日期格式。
4. 选择目标 DE。
5. 选择字段映射方式并逐字段确认。
6. 选择 Data Action。
7. 检查主键、空值和字段长度。
8. 保存并在测试文件上手动执行。
9. 对照源文件行数、导入成功数、失败记录和目标 DE 数据。
10. 确认无误后，将 Import Activity 加入 Automation。

## 9. 常见问题
**Q1：文件找不到**
确认 File Location、目录、文件名 Pattern、大小写、扩展名和文件到达时间。

**Q2：日文变成乱码**
确认源文件编码与 Import Definition 设置一致；不要仅凭 Excel 打开正常就判断文件编码正确。

**Q3：部分字段没有更新**
检查字段映射、目标字段、Data Action 和空值处理规则。更新文件中未提供的字段如何处理，必须按具体 Import Definition 和数据动作测试，不应凭猜测认定会清空或保留。

**Q4：导入记录数比文件行数少**
检查 Header、空行、重复主键、格式错误、字段长度和导入错误日志。

## 10. 学习 Checklist
- [ ] 能解释 Import Activity 与 File Transfer 的区别。
- [ ] 能配置 File Location 和 File Naming Pattern。
- [ ] 能选择 Header / Ordinal / Manual 映射。
- [ ] 能区分 Add Only、Update Only、Add and Update、Overwrite。
- [ ] 能通过导入结果和目标 DE 验证数据。
