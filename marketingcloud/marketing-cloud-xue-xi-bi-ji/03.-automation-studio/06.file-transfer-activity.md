# 06. File Transfer Activity

## 1. 学习目标
理解 File Transfer Activity 的 Safehouse 处理机制，能够区分文件移动、解压、解密和 Import，并设计安全可靠的文件处理流程。

## 2. File Transfer Activity 是什么
File Transfer Activity 用于处理 Marketing Cloud Engagement 文件位置之间的文件操作。常见用途包括将文件移动到 Safehouse、解压缩或解密，以及将 Safehouse 中的文件移动到指定 FTP Location。

它不负责把 CSV 行解析并写入 Data Extension；该工作由 Import Activity 完成。

## 3. Safehouse 是什么
Safehouse 是 Marketing Cloud Engagement 用于安全暂存文件的内部位置。需要通过平台支持的活动和授权方式访问，不应把它当作普通 FTP 目录或长期归档空间。

## 4. 常见操作
具体选项名称会随界面和产品更新而变化，常见任务包括：
- Manage File：对文件执行解压或解密等处理。
- Move a File From Safehouse：将 Safehouse 文件移动到配置的 FTP Location（旧界面可能显示 Upload）。
- 将文件从指定位置转移到平台安全暂存区域，以供后续活动处理。

## 5. 与其他 Activity 的区别
| Activity | 作用 |
|---|---|
| File Transfer | 移动、解压或解密文件 |
| Import / Data Copy | 解析文件并写入 List / DE |
| Data Extract | 从 Marketing Cloud 生成导出文件 |
| SQL Query | 从 DE / Data Views 查询并加工数据 |

## 6. 实际操作：处理压缩文件
1. 确认上游文件格式、压缩方式和加密方式。
2. 确认文件所在 FTP Location 和文件名。
3. 在 Activities 创建 File Transfer Activity。
4. 选择相应文件管理操作和目标位置。
5. 保存后在测试文件上执行。
6. 确认 Safehouse 中生成预期文件。
7. 将后续 Import 放在另一个 Step，确保文件处理完成后再导入。
8. 验证导入结果并按项目要求归档原文件。

## 7. 安全与时间注意事项
- 不要将 Safehouse 当作永久存储。
- 只授予必要的 FTP / 文件访问权限。
- 对敏感数据使用组织批准的加密方式和密钥管理流程。
- Salesforce 文档指出，File Transfer 对远端 FTP 服务器时间的判断按 UTC 处理；如果服务器不是 UTC，需要考虑时间差并使用适当的系统缓冲设置。
- 文件名和目录应避免覆盖尚未处理的文件。

## 8. 常见问题
**Q1：File Transfer 成功，为什么 DE 没有数据？**
File Transfer 只处理文件，不代表 Import 已执行。检查后续 Import Activity、Step 顺序和导入结果。

**Q2：为什么 Import 找不到文件？**
确认文件是否已进入预期位置、文件名 Pattern 是否匹配，以及 File Transfer 的目标位置是否正确。

**Q3：为什么解压或解密失败？**
确认压缩格式、加密方式、密钥配置和文件完整性。若使用不受支持的密钥方案，应联系 Salesforce Support 或管理员确认可行方案。
