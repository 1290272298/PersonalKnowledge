# 05. Spam

## 学习目标
理解 Spam Complaint、Spam Folder 投递和垃圾邮件信誉之间的区别。

## 1. 两种不同概念
- Spam Complaint：用户或邮箱服务商反馈“这是垃圾邮件”，可能通过 Feedback Loop 回传。
- Spam Folder Placement：邮件被接收方接受，但放入 Junk / Spam 文件夹。

Complaint 是反馈事件；Spam Folder 是投递位置。二者相关但不相同。

## 2. 常见原因
- 未获得明确许可或订阅预期不清晰
- 发送频率过高
- 退订入口不明显或处理不及时
- 内容与订阅时承诺不符
- 发件域名/IP 信誉下降
- 认证、链接或品牌识别不一致

## 3. 处理投诉
Marketing Cloud 可通过 ISP Feedback Loop 等机制接收投诉反馈，并将其按配置处理为退订/抑制。必须尊重退订和投诉状态，不得通过更换 DE、Subscriber Key 或发送方式绕过抑制。

## 4. 降低投诉风险
- 明确订阅来源和许可证据
- 使用双重确认（适合业务场景时）
- 提供清晰退订方式
- 让 From Name / Domain 与品牌一致
- 发送内容与用户预期相符
- 控制频率并清理长期不活跃地址

## 5. 排查步骤
1. 查看 Complaint / Unsubscribe 数据。
2. 按域名、Campaign、发送量和受众来源分组。
3. 检查订阅来源、发送频率和内容预期。
4. 检查 SPF / DKIM / DMARC 和信誉。
5. 修正流程并持续监控投诉率。

## Checklist
- [ ] 订阅许可来源可追踪
- [ ] 投诉反馈及时处理
- [ ] 退订路径清晰有效
- [ ] 发送频率符合用户预期
- [ ] 投诉按来源和 ISP 监控
