# 01. Email Studio 介绍

## 1. 学习目标

学习完成后，应能够说明 Email Studio 在 Marketing Cloud Engagement 中承担的职责，并理解一封邮件从内容制作、发送配置、受众选择到发送后 Tracking 的基本流程。

## 2. Email Studio 是什么

Email Studio 是 Marketing Cloud Engagement 中用于邮件营销和邮件发送管理的产品功能集合。它并不只是邮件编辑器，而是与 Content Builder、Subscriber 数据、发送配置和 Tracking 等能力协同工作。

常见工作包括：

- 创建和管理邮件内容。
- 准备发送对象及个性化数据。
- 配置发送身份、投递方式和发送分类。
- 执行测试发送、即时发送或定时发送。
- 查看发送、打开、点击、退信和退订等事件。
- 管理 Subscriber 及邮件订阅状态。

## 3. 主要组成与职责

| 组成 | 核心职责 | 需要回答的问题 |
|---|---|---|
| Content Builder | 管理邮件、模板、图片和可复用内容块 | 邮件内容是什么？ |
| Email | 定义邮件主题、预览文字、正文和个性化逻辑 | 要发送哪一封邮件？ |
| Send Classification | 集中定义发送分类，并关联 Sender / Delivery Profile | 这次发送采用什么分类和配置？ |
| Sender Profile | 定义 From Name、From Email 等发件人信息 | 收件人看到是谁发的？ |
| Delivery Profile | 定义发送 IP 选择及 Header / Footer 等投递信息 | 使用什么投递配置？ |
| Audience | 定义发送对象、数据来源和排除对象 | 发给谁？ |
| Send | 执行发送或安排发送 | 何时执行发送？ |
| Tracking | 记录发送及互动事件 | 发送后发生了什么？ |
| Subscription | 管理 Subscriber 和订阅/退订状态 | 是否允许继续发送？ |

## 4. 邮件发送生命周期

    准备发送数据
        ↓
    在 Content Builder 创建 Email
        ↓
    检查邮件属性、内容和个性化
        ↓
    选择 Send Classification
        ↓
    确认 Sender Profile / Delivery Profile
        ↓
    选择 Audience、排除对象及 Publication List（如适用）
        ↓
    Preview / Test Send
        ↓
    Review 并执行 Send 或 Schedule
        ↓
    Tracking：Sent / Open / Click / Bounce / Unsubscribe
        ↓
    分析结果并处理异常

这是一条概念流程。实际界面中的步骤顺序会因发送入口、经典邮件或 Content Builder 邮件、Triggered Send、Journey Builder 等场景而不同。

## 5. 发送前必须明确的四个问题

1. **发送什么？** 已完成审核的 Email、Subject、Preheader 和内容。
2. **发送给谁？** 目标 DE / List / Audience，以及排除规则。
3. **采用什么发送配置？** Send Classification、Sender Profile、Delivery Profile。
4. **是否允许发送？** Subscriber 状态、订阅范围、合规要求和抑制规则。

## 6. 实际操作：认识当前账号的邮件功能

1. 登录 Marketing Cloud Engagement，确认当前所在 BU。
2. 打开 Content Builder，确认是否能查看邮件、模板和 Content Block。
3. 查看 Setup 中的 Sender Profile、Delivery Profile 和 Send Classification（需要相应权限）。
4. 在 Email Studio 中查看可用的发送入口及 Tracking。
5. 记录当前账号中可用的功能名称；不要假设所有 BU 都具有相同菜单或权限。

## 7. 常见误区

- **误区：Content Builder 就是 Email Studio。** Content Builder 是内容资产管理和编辑能力；发送还需要受众和发送配置。
- **误区：Sender Profile 决定发送 IP。** Sender Profile 主要定义 From 信息；IP 和 Header / Footer 等属于 Delivery Profile 的配置范围。
- **误区：选择 DE 就代表所有记录都会发送。** 仍需考虑 Sendable 配置、Subscriber 状态、排除规则、List Detective 等限制。
- **误区：Delivered 代表用户已阅读。** Delivered 是投递事件，不代表用户实际阅读。
- **误区：Open 绝对代表人工打开。** Open Tracking 依赖像素加载，可能受到邮件客户端隐私保护、图片加载设置等因素影响。
