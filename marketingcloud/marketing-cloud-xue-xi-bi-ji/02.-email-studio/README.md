# 02. Email Studio

## 本章学习目标

本章围绕 Marketing Cloud Engagement 的邮件制作、发送配置、受众选择、发送执行、Tracking 与订阅管理，建立从准备数据到发送后分析的完整知识体系。

完成本章后，应能够：

- 说明 Content Builder、Email Studio Send Flow、Send Classification 之间的关系。
- 创建可复用的 Content Block，并制作可测试的 Email。
- 理解 Sender Profile、Delivery Profile 与 Send Classification 的职责边界。
- 检查 Sendable Data Extension、Subscriber Key、Email Address 与发送受众。
- 执行 Test Send、正式发送和 Scheduled Send 前检查。
- 解释 Sent、Open、Click、Bounce、Unsubscribe 等指标的含义和限制。
- 区分 List、Publication List、Universal、Global 等退订范围。

## 学习路线

| 顺序 | 主题 | 学习重点 |
|---|---|---|
| 01 | Email Studio 介绍 | 整体架构与邮件发送生命周期 |
| 02 | Content Builder | 内容资产、Folder、Template、Content Block |
| 03 | Email | 邮件结构、属性、个性化与预览 |
| 04 | Send Classification | Commercial / Transactional 与配置组合 |
| 05 | Sender Profile | From Name、From Address、Reply-To |
| 06 | Delivery Profile | IP、Header、Footer 与投递配置 |
| 07 | Send | Audience、DE、发送流程、测试与正式发送 |
| 08 | Tracking | 发送事件、指标解释与分析限制 |
| 09 | Subscription / Unsubscribe | Subscriber 状态、Publication List 与退订范围 |

## 建议实践环境

建议使用非生产 BU、专用测试 Data Extension 和已获授权的测试邮箱完成练习。不要向真实客户或未经同意的地址发送测试邮件。

先完成 01～06 的概念和配置理解，再使用 07 完成一次端到端测试发送，最后通过 08、09 检查 Tracking 和退订行为。

> 注意：菜单名称、可用功能、权限和发送行为可能因账号版本、BU 设置、产品许可及账户配置而不同。实际操作时应以当前账号界面和 Salesforce 官方文档为准。
