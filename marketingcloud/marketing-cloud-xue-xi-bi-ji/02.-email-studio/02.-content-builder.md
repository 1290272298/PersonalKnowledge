# 02. Content Builder

## 1. 学习目标
理解 Content Builder 的内容资产管理职责，能够创建和管理 Content Block、Email 与 Folder，并完成基本预览和测试。

## 2. Content Builder 是什么
Content Builder 是 Marketing Cloud Engagement 的内容资产管理和编辑功能。它将邮件、图片、文档、模板和内容块等资产集中管理，支持可视化编辑和 HTML 等制作方式。

它解决两个问题：
- **内容制作**：创建邮件正文、图片、按钮、动态内容等。
- **内容管理**：通过 Folder、搜索、标签和共享权限组织内容资产。

Content Builder 本身不决定邮件最终发送给谁，也不等同于发送执行。

## 3. 常见内容资产

| 资产 | 用途 | 示例 |
|---|---|---|
| Email | 完整邮件消息 | 月度 Newsletter |
| Template | 邮件布局模板 | 公司统一邮件版式 |
| Content Block | 可复用内容模块 | Header、Footer、免责声明 |
| Image | 图片资产 | Banner、商品图片 |
| HTML / Code Snippet | 自定义代码或片段 | AMPscript、HTML |
| Dynamic Content | 按数据条件显示不同内容 | 不同会员等级显示不同 Banner |

具体资产类型和编辑器能力可能因账号配置、功能启用情况而不同。

## 4. Content Block 的作用
Content Block 是可以插入邮件并重复使用的内容模块，适合将多个邮件都会出现的区域独立管理。

示例结构：

    Newsletter Email
    ├─ Header Block
    ├─ Greeting Block
    ├─ Campaign Content Block
    ├─ CTA Button Block
    └─ Footer Block

优点：
- 统一维护重复内容。
- 减少复制粘贴造成的不一致。
- 可按 BU、Campaign 或用途组织内容资产。
- 便于多人协作和复用。

注意：修改被多个邮件引用的共享内容块，可能影响使用该内容块的邮件。修改前应确认引用关系，并按项目发布流程测试。

## 5. Folder 管理建议

    Content Builder
    ├─ 00_Shared
    │  ├─ Header
    │  └─ Footer
    ├─ 01_Templates
    ├─ 02_Campaign
    │  ├─ 2026
    │  └─ 2027
    ├─ 03_Images
    ├─ 04_ContentBlocks
    └─ 99_Archive

这是命名示例，不是 Salesforce 强制目录结构。多 BU 环境应明确资产共享范围和访问权限，避免将仅适用于某个 BU 的内容误用于其他 BU。

## 6. 实际操作：创建 Content Block
1. 打开 Content Builder。
2. 选择 Create。
3. 选择 Content Block，并选择适合的内容类型。
4. 编辑文字、图片、HTML 或其他内容。
5. 预览桌面和移动端显示效果。
6. 保存时填写便于识别的 Name 和 Description。
7. 选择正确的 Folder；如涉及跨 BU 使用，确认共享设置。
8. 重新打开保存后的内容，确认内容、链接和图片正常。

## 7. 实际操作：创建 Email
1. 在 Content Builder 选择 Create。
2. 选择 Email Message。
3. 选择创建方式，例如 Template、HTML、Text Only 或 Existing Email（可用选项依账号功能而定）。
4. 填写邮件名称等属性。
5. 在编辑画布中添加 Content Block、图片、按钮和正文。
6. 设置 Subject、Preheader 等邮件属性（如当前创建流程提供）。
7. 使用 Preview 检查内容与个性化结果。
8. 执行 Test Send 前确认测试受众和测试邮箱。
9. 保存邮件，并通过 Email Studio Send Flow 或适用的发送入口执行发送。

## 8. 检查重点
- 图片是否使用有效资源，是否存在失效链接。
- CTA 按钮是否指向正确页面。
- HTML 在常见邮件客户端和移动设备中的显示是否正常。
- 动态内容在不同测试数据下是否显示正确。
- 共享 Content Block 修改是否影响其他邮件。
- 邮件 Footer 是否包含适用的公司信息、地址及退订方式。

## 9. 常见问题
**Q1：为什么邮件中看不到刚刚修改的 Content Block？**
确认邮件是否引用了正确的内容块、修改是否保存，以及邮件是否需要重新打开或重新保存。对于共享内容，检查引用的资产是否为预期版本。

**Q2：Content Block 可以跨 BU 使用吗？**
需要结合资产共享设置、BU 权限和当前账号配置确认。不能仅凭 Folder 名称判断是否共享。

**Q3：保存 Email 后是否已经发送？**
没有。保存内容资产和执行邮件发送是不同的操作。
