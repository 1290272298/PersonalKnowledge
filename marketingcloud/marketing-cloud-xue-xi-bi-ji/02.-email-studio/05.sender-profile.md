# 05. Sender Profile

## 1. 学习目标
理解 Sender Profile 管理的发件人信息，能够检查 From Name、From Email Address 和邮件发送时实际使用的发件人配置。

## 2. Sender Profile 是什么
Sender Profile 用于集中定义邮件的 From 信息，使多个发送可以复用同一套发件人信息。

通常涉及：
- From Name：收件人看到的发件人显示名称。
- From Email Address：收件人看到的发件人邮箱地址。

Reply-To（回复地址）在具体发送配置和账号界面中可能有独立设置或相关选项；应以当前 Sender Profile 编辑界面和实际邮件头为准，不要将 Reply-To 与 From Address 视为同一个字段。

## 3. 使用示例

| 用途 | From Name | From Email Address |
|---|---|---|
| 营销活动 | ABC Marketing | campaign@example.com |
| 客户支持 | ABC Support | support@example.com |
| 系统通知 | ABC Service | notice@example.com |

以上均为示例地址，实际发送必须使用经过组织授权、域名认证和合规检查的发件人地址。

## 4. Sender Profile 与 Send Classification

    Send Classification
           │
           └── Sender Profile
                  ├── From Name
                  └── From Email Address

Sender Profile 可以被多个 Send Classification 或发送配置引用。修改共享 Profile 前，应确认其他发送是否依赖它。

## 5. 实际操作：检查 Sender Profile
1. 打开 Marketing Cloud Engagement Setup。
2. 在 Quick Find 中搜索 Sender Profile。
3. 查看现有 Profile 的 Name、From Name 和 From Email Address。
4. 确认地址属于组织允许使用的发件域名。
5. 确认该 Profile 被哪些 Send Classification 或发送流程使用。
6. 使用测试邮件检查收件箱显示的 From 信息。
7. 如需修改，先在测试配置中验证，再按变更流程发布。

界面位置可能随账号界面更新而变化。

## 6. 发件人配置检查
- From Name 是否清楚、可识别。
- From Email Address 是否真实有效且获授权。
- 发件域名是否符合 SPF、DKIM、DMARC 等组织策略。
- Reply-To 是否能正常接收和处理回复。
- 发件人显示是否符合品牌、客户沟通和合规要求。

## 7. 常见问题
**Q1：为什么邮件中的 From 与 Sender Profile 不一致？**
检查发送交互是否覆盖了 Sender Profile 的属性、是否选择了其他 Send Classification，以及实际发送入口是否有独立发件人设置。

**Q2：From Address 可以随便填写吗？**
不可以。应使用组织授权的地址和已配置认证策略的域名。未经授权使用他人域名可能造成认证失败和投递问题。

**Q3：Sender Profile 决定发送 IP 吗？**
不是。发送 IP 选择属于 Delivery Profile 的职责范围。
