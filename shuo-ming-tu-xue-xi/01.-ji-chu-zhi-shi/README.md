# 01. 说明图制作基础知识

本章是整套课程的起点。先理解说明图的作用、常见类型和制作流程，再开始学习如何站在日本客户的角度组织信息。

## 本章学习目标

- 理解说明图（説明図・図解）的含义。
- 区分说明图、普通 PPT 和操作手册。
- 了解日本企业常见的说明图类型。
- 判断什么时候应该使用说明图。
- 掌握从确认目的到交付文件的基本制作流程。
- 能够把简单的文字业务说明整理成流程草图。

## 学习顺序

1. 阅读[说明图制作基础知识](01.-shuo-ming-tu-ji-chu.md)。
2. 完成“整理原始业务信息”练习。
3. 根据练习内容画出第一张流程草图。
4. 对照本章完成标准进行自检。

## 本章成果

完成一张简单的业务处理流程草图。草图需要有标题、处理步骤、判断条件和处理结果；不得添加原始资料中没有定义的业务规则。

## 下一步

完成本章后，进入第 02 章，学习日本客户的阅读习惯与思考方式。
