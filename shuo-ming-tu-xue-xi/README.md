# 日本客户向け说明图制作学习指南

本学习区帮助没有设计经验的初学者，从理解日本客户、整理业务信息、编写日语说明，到制作流程图、系统结构图和数据流向图，逐步掌握商务说明图的制作方法。

## 1. 学习目标

完成本学习区后，你应该能够：

- 判断一项业务内容是否适合制作成说明图。
- 从设计书、业务说明和系统资料中提取必要信息。
- 根据说明目的选择流程图、系统结构图、数据流向图、对比图等。
- 用简洁、准确的日语表达处理步骤、条件和注意事项。
- 使用 draw.io、PowerPoint 等工具制作说明图。
- 从日本客户的阅读视角检查内容是否清楚、准确。
- 在 AI 辅助下提高整理和制作效率，同时核实业务事实。

## 2. 适合哪些人？

- 需要向日本客户说明业务或系统内容的工程师。
- 需要制作设计说明、系统说明、操作说明或项目汇报资料的人员。
- 日语可以进行基本工作沟通，但不熟悉商务图表设计的人。
- 没有设计基础，希望从零开始学习的人。

本课程不要求具备美术或专业设计背景。重点是信息整理、逻辑表达和准确沟通。

## 4. 推荐学习方法

建议每天学习 30～45 分钟。每一章按以下顺序进行：

1. 先理解基础概念。
2. 阅读实际业务案例。
3. 按照步骤完成练习。
4. 对照本章完成标准进行自检。
5. 将练习成果保存下来，作为个人模板和作品集。

不要只阅读不练习。说明图是一项实践技能，需要通过反复整理、绘制和修改来掌握。

## 6. 本学习区的基本原则

### 6.1 先确认事实，再设计图形

说明图必须以已确认的业务资料、设计书和客户要求为依据。资料中没有明确的条件、处理方式或系统行为，应标记为「要確認」，不能自行补充。

### 6.2 先整理逻辑，再使用工具

不要拿到资料就直接打开 PowerPoint 开始画图。先确认目的、阅读对象、处理步骤、判断条件和处理结果，再决定图形结构。

### 6.3 以阅读者能否理解为判断标准

漂亮不是唯一标准。阅读者应该能快速找到主题、理解阅读顺序、看懂对象之间的关系，并区分正常处理和异常处理。

### 6.4 遵循客户和项目规范

本手册中的颜色、符号、日语表达和文件格式是学习示例。实际项目中，客户指定的模板、术语、设计规范和交付要求优先。

## 7. 推荐工具

| 工具 | 主要用途 | 学习顺序 |
|---|---|---|
| ChatGPT | 整理资料、优化日语、检查表达 | 先学习基础用法 |
| draw.io | 流程图、系统结构图、数据流向图 | 优先掌握 |
| PowerPoint | 客户说明资料、综合页面、正式交付 | 优先掌握 |
| Figma | 精细视觉设计、组件化管理 | 后续进阶 |

工具的详细操作会在第 07 章介绍。

## 8. 学习成果

建议最终完成以下三份作品：

1. **业务处理流程图**：展示业务步骤、判断条件和处理结果。
2. **系统数据连携图**：展示数据来源、传递方向、处理系统和输出结果。
3. **系统操作说明图**：展示用户操作步骤、画面变化和注意事项。

完成这三份作品，并通过第 10 章的质量检查后，就可以认为已经具备基础的说明图制作能力。
