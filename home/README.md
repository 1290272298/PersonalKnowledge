# 学习与知识实践中心

欢迎来到学习与知识实践中心。

这里汇集了两个相互独立、持续整理的学习体系：**Salesforce Marketing Cloud 产品与项目知识库**，以及**从日语基础到 JLPT N1 的系统化日语学习资料**。

两个体系面向不同的学习目标，分别维护内容、章节结构与学习路径。你可以根据自己的需要选择入口，不必按照同一顺序学习。

---

## 选择学习方向

### 01｜Salesforce Marketing Cloud

系统学习 Salesforce Marketing Cloud 的产品功能、数据模型、自动化、开发集成与邮件送达，并结合实际项目经验整理问题分析和解决方法。

**主要内容**

| 学习领域 | 内容范围 |
|---|---|
| 产品基础 | 产品体系、Business Unit、Subscriber、Contact、Data Extension |
| 营销执行 | Email Studio、Automation Studio、Journey Builder |
| 数据与个性化 | Contact Builder、Personalization |
| 开发与集成 | SQL、AMPscript、SSJS、REST API、SOAP API、OAuth |
| 邮件送达 | Bounce、Held、Spam、SPF、DKIM、DMARC |
| 项目实践 | 实际问题、调查过程、原因分析、解决方案与验证结论 |

**推荐学习方式**

1. 从基础知识开始，理解核心对象和数据关系。
2. 学习 Email Studio、Automation Studio 与 Journey Builder，掌握主要营销执行流程。
3. 根据工作需要继续学习 Contact Builder、Personalization、开发和 API 集成。
4. 遇到实际问题时，参考问题记录，并将经过验证的经验整理归档。

[进入 Marketing Cloud 学习笔记](../marketingcloud/README.md)

### 02｜日本語学習

面向日语初学者及进阶学习者，按照语言能力的发展顺序，系统整理基础知识、文法、語彙、漢字、JLPT、日常会話与ビジネス日本語。

**主要内容**

| 学习领域 | 内容范围 |
|---|---|
| 01 日本語の基礎 | 平假名、片假名、发音、基本文型、助词与活用 |
| 02 文法 | 基本文法、复句、授受、条件、敬语及各类表达 |
| 03 語彙 | 日常生活、社会、工作、IT、情感及场景词汇 |
| 04 漢字 | 部首、音读与训读、笔顺、熟语及分级汉字 |
| 05 JLPT対策 | N5～N1 的学习重点与原创练习 |
| 06 日常会話 | 问候、购物、餐饮、交通、旅行及日常交流 |
| 07 ビジネス日本語 | 商务敬语、邮件、电话、会议、报联商与业务文书 |
| 08 読解・聴解 | 阅读理解、文章结构、信息检索、听力与跟读训练 |
| 09 学習資料 | 学习计划、复习表、错题整理、模拟练习与学习资源 |

**推荐学习方式**

1. 初学者先从日本語の基礎开始，建立文字、发音和基本句型基础。
2. 将文法、語彙与漢字结合学习，并通过例句理解实际用法。
3. 使用日常会话和商务日语内容，将知识应用到真实场景。
4. 根据目标选择 N5～N1 对应的 JLPT 学习内容。
5. 通过读解、听解和复习资料持续检查薄弱环节。

## 如何使用本站

- **按体系学习**：进入对应知识库，按照该体系自己的目录和推荐顺序学习。
- **按主题查找**：使用站内搜索，通过产品名称、功能名称、语法项目或关键词定位内容。
- **结合实践**：学习概念后，尽量通过配置、例句、练习或实际场景加深理解。
- **持续复习**：定期回顾已学内容，记录疑问、错误和需要进一步确认的知识点。

## 内容与资料原则

- 尽量使用原创整理的说明、示例、练习和图示。
- 涉及产品功能、考试制度、权限、版本或外部资料时，优先核对官方或可信来源。
- 区分通用知识、官方说明与特定环境下的项目验证结论。
- 尊重第三方资料的版权与使用条件，不将未经授权的教材或内容直接转载为本站原创。
- 对可能发生变化的信息，应结合资料来源、适用范围和实际环境再次确认。

## 关于本站

本站是持续维护的个人学习与实践知识库。两个学习体系会根据学习进度、产品变化和实际使用反馈分别更新。

希望这里的资料能够帮助你建立知识体系、解决实际问题，并把学到的内容真正应用起来。
