# 欢迎来到「学习和产品知识库」

这里整理了两套可以独立学习的资料：

- **Marketing Cloud**：学习 Salesforce Marketing Cloud 是什么、如何管理联系人和数据、如何发送邮件、如何设置自动化流程，以及遇到问题时如何排查。
- **日本語学习**：从日语文字、发音和基础语法开始，逐步学习词汇、汉字、日常会话、商务日语和 JLPT。

你不需要一次看完所有内容。先选择自己想学的方向即可。

## 我是零基础，应该从哪里开始？


### 想学习 Salesforce Marketing Cloud

建议按照下面顺序：

1. **先认识产品**：了解 Marketing Cloud 是什么，以及它能做什么。
2. **理解基础概念**：认识 BU、Subscriber、Contact、Data Extension 等常见名词。
3. **学习实际功能**：了解 Email Studio（邮件制作与发送）、Automation Studio（自动化任务）和 Journey Builder（客户旅程）。
4. **再学习进阶内容**：根据需要学习数据管理、Personalization、SQL、API 和系统集成。
5. **遇到问题时查案例**：到「问题记录」中查找类似现象、调查方法和解决思路。

[进入 Marketing Cloud 学习笔记](../marketingcloud/README.md)

### 想从零开始学习日语

建议按照下面顺序：

1. **01 日语基础**：先学平假名、片假名、发音和基本句型。
2. **02 语法**：学习句子怎么组成，以及不同语法表达的意思。
3. **03 词汇、04 汉字**：每天积累词汇和汉字，并结合例句复习。
4. **06 日常会话**：把学过的内容用在购物、餐饮、交通和日常交流中。
5. **05 JLPT 对策**：根据自己的目标选择 N5、N4、N3、N2 或 N1。
6. **08 阅读与听力、09 学习资料**：练习理解能力，并利用复习表和错题记录检查不足。

[进入日语学习资料](../ri-ben-yu-xue-xi/README.md)

## 怎样使用本站？

- **看左侧目录**：点击分类名称，可以展开或收起里面的文章。
- **使用顶部搜索**：输入你记得的关键词，例如「退订」「自动化」「助词」「N2」，不必记住文章的完整标题。
- **看文章目录**：打开文章后，右侧会显示本页的小标题，点击即可跳到对应位置。
- **遇到专业词汇**：文章会尽量保留产品或日语原有术语，并在标题或正文中补充中文解释。
